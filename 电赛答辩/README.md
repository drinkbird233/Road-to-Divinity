# 电机控制实验装置（2026 佛山大学电子设计竞赛 A 题）

## 内容

- `最终版本/` — Keil MDK 工程源码（Hardware 驱动、Library 标准外设库、User 应用、Start 启动文件）
- `A题-电机控制实验装置-2026佛山大学电子设计竞赛题目(1).pdf` — 赛题
- `A题设计报告最终版.docx` — 设计报告
- `A题源代码.docx` — 源代码说明
- `答辩稿.docx` — 答辩讲稿

## 硬件

- 主控：STM32F103C8T6
- 外设：编码器、直流电机、PWM、OLED、按键、串口

## 构建

用 Keil MDK 打开 `最终版本/Project.uvprojx`，编译下载。Objects、Listings 等编译产物不入库。
