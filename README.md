# Road to Divinity

个人嵌入式项目仓库，一个项目一个目录。

## 项目

- **简易示波器** — STM32F103C8T6 + ST7735S，ADC + DMA 采样、软件触发对齐、TIM3 输入捕获测频。见 [简易示波器/](简易示波器/)
- **电赛答辩** — 2026 佛山大学电子设计竞赛 A 题：电机控制实验装置，含赛题、设计报告、答辩稿与 Keil 源码。见 [电赛答辩/](电赛答辩/)
- **MP3 播放器** — STM32F407ZGT6 + ES8388 + SDIO/FatFs，minimp3 解码 MP3，FreeRTOS + 播放列表 + LVGL 9.4 音乐播放器 UI（触摸/四键控制），耳机/喇叭双通道输出，支持 8k~48kHz 与单声道。见 [MP3播放器/](MP3播放器/)
- **校赛智能车** — STM32F407ZGT6 循迹小车：8 路灰度循迹 + HWT101 陀螺仪 + K230 视觉 + 双编码器速度闭环，HAL + FreeRTOS 5 ms 控制节拍，元素状态机（弯道/S 弯/圆环岛/盲走/十字），蓝牙命令行可实时整定参数。见 [校赛智能车/](校赛智能车/)

## 约定

- 每个项目一个独立目录
- 目录内 README 说明功能、硬件与构建方式
- 编译产物不入库
