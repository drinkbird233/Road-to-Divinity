## 4. 六次失败 → 六个根因（按发现顺序）

这一节是本次任务最有价值的部分：**每一次失败对应一个真实的设计缺陷**，不是参数没调好。

### ① 出口"看见线就走"，形状判据拿不到数据

`EL_BLIND` 的出口只要 `cnt>0` 连续 2 拍就成立，实测出口那一拍 `cnt=2`，
而环岛形状判据要 `cnt>=3` → 差一路，`[el] 6` 永远不出现。

**修**：出口改成"锁存形状再决定"——出口窗口内只要**任意一拍**见过入口形状就锁存，
一直辨不清就最多再走 `CFG_BLIND_EXIT_MM(60)`。

### ② 盲走判据只写在 `EL_STRAIGHT` 里

断口前的胶带残段（`raw=3F`，线跑到最左两路）让车被判成"弯道"进 `EL_CORNER`；
而 `EL_CORNER` 的丢线分支里**没有盲走判据**，于是车绕着残段以 32 mm/s 爬了 10.5 s，
最后"丢线超时"停车。

**修**：判据抽成 `blind_win_hit / blind_cnt_ok / blind_seq_ok / blind_want / blind_go`，
三个调用点共用：`EL_STRAIGHT` 丢线分支、`EL_STRAIGHT` 顶部（里程窗无条件入口）、
`EL_CORNER` 丢线分支。

### ③ 里程窗"抢跑"后 60 mm 就退出

窗口下界 7950 比胶带真正的断点早约 100 mm。车在**线还在**的时候被抢进盲走，
然后又看见线 → 60 mm 后退出去 → 正好压在断口起点 → 连做两个假转弯（整趟崩）。

**修**：`s_blind_needlost` —— 抢跑进来的那次盲走，**必须先真的丢一次线**才允许退出。

### ④ `4 路` 就判环岛：车偏到一边也算"分叉"

`raw=F0`（压线 4~7，只是车偏右）满足旧的 `count>=4 && right_edge==7` → 误进环岛。

**修**：门槛 4 → 5。

### ⑤ 环岛入口提前 1.2 m

`CFG_BLIND_NEXT_LOOP=1` 让 `[el] 6` 在**盲走出口（9664）**就触发，
而真顶点在 10790~10930。中间 1.2 m 状态机在环岛态里普通跟线，真顶点反而不判。

**修**：`CFG_BLIND_NEXT_LOOP = 0`，入口统一交给 `EL_STRAIGHT` 的真分叉判据。

### ⑥ 顶点是"对称宽黑"，位置环没有理由选边

顶点实测 `raw=C0`（`mask=FC`，压线 2~7）或 `raw=C1`（`mask=7C`，压线 2~6），
`err≈0`。位置环看到误差为零 → 直着过去。而 `EL_LOOP_IN` 在"看得见线"时
`e_bias = 0`（2026-11-23 为救圆形环岛改的），等于完全不选边。

**修**：`EL_LOOP_IN` 恢复"一直带偏置"（±2.5，80 mm），能把航向拉 20~30°，
足够咬住六边形那条边；方向用 `CFG_LOOP_EDGE_DIR` 写死。

### ⑦（收尾）出环岛后终点不停车

`s_finish_armed` 只在"走出盲走"时置位。调试模式从断口起步（没走盲走）→
终点黑带被当普通路口开过去。另外两条判据各用各的计时器，路口 15 ms 总赢终点 40 ms。

**修**：路口分支加 `&& !s_finish_armed`；并在 `EL_LOOP_OUT` 一进来就
`s_finish_armed = 1`。

## 7. 遗留问题（不影响完赛，但值得知道）

| # | 问题 | 影响 | 建议 |
|---|---|---|---|
| 1 | 环岛入口依赖"连续压线 ≥5 路" | 若某次车的横向位置特别靠外，可能只看到 4 路 → 不触发（6 次里失败 1 次就是这个） | 可加"里程 + 宽黑"双条件（顶点在起点后 1.05~1.1 m） |
| 2 | 环岛 10.96 s，接近 12 s 超时 | 若打滑更多会靠超时退出，位置随机 | 把超时抬到 14 s，或降环岛速度 |
| 3 | 盲走是纯开环 | 1° 航向误差 = 26 mm 横偏，靠"发车摆正"保证 | 增加"末段左右扫线"兜底 |
| 4 | 45° 斜切段没有专门处理 | 靠循迹过，速度快时会切角 | 提速后重点观察 |
| 5 | 圆形环岛（右上）因 `CFG_LOOP_AFTER_BLIND=1` 不进环岛态 | 靠普通循迹过，目前没问题 | 若需正式处理，改成"里程区间"判据 |

## 8. 现场操作流程（每次上车）

```
1. 把车放在起点（黑带之后那段直道），车头顺胶带、摆正
2. D 0            # 方向自动（本赛道左右弯都有，不能锁）
3. N 0            # 确认调试开关是关的（整圈模式）
4. a              # 起步
```

单独练环岛（分段调试）：

```
1. 车放"断口结束、胶带重新出现"之后 20~30 cm
2. N 1            # 假装盲走已完成
3. a
```
