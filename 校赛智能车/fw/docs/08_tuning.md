# 08 现场调参手册（交付版）

> 目标：接手的人**不看我、不重新编译**，只用电脑串口就能把车调好。
> 所有调参参数都能用命令在线改，改错了按复位就回到默认值。

---

## 0. 五分钟跑起来

```
① 上电（12V 电池 + 5V 逻辑，见 pin_plan.md）
② 串口助手连 COM 口，115200 8N1
③ 车摆到线中间，发命令：
   a            ← 启动循迹
   x            ← 停车
```

上电后应该看到：

```
[track] probe 0x12 = 1 (swapSCL/SDA=0)
[car] boot ok, sysclk=168000000
[app] heap free = 23936
[app] create ctrl=1 comm=1 ui=1 heap=17968
[ctrl alive]
[comm alive]
[ui alive]
```

**然后完全安静**（每 0.5 秒一个 `.` 心跳，收到第一条命令后停止）。安静是对的，出问题才会有输出。

## 1. 连接方式

| 方式 | COM 口 | 说明 |
|---|---|---|
| **USB-TTL（CH340）** | 通常是 COM5 | **最可靠**，调参首选 |
| 蓝牙 HC06 | COM9 / COM10 | 无线，但**电机动作时容易掉线**（见第 7 节） |

- 波特率 **115200**，8 数据位，无校验，1 停止位
- 命令**不用回车**也能执行（150 ms 静默后自动执行），回车也可以
- 回复前缀统一是 `[cli]`

### 如果想用蓝牙

1. 配对 HC06（PIN 1234）
2. 选标"**传出**"的 COM 口
3. 上电顺序很重要：**先给板子上电，再打开串口**（Windows 是在打开端口那一刻才去连蓝牙的）

```
串口助手 → 输入 c      → 板子回显 ">c" 再回 "[cli] steer kp=70.0 ..."
```

- 收不到 `>` 说明命令没进板子：查 COM 口、查配对、查上电顺序。
- **不用敲回车**：最后一个字节之后静默 150 ms 就自动执行（`cli_poll`）。
  串口助手勾上"发送新行"更稳，两者都支持。
- 日志同时从 USART1（CH340）和 USART3（蓝牙）发出，只接一路也能看全。

> ⚠️ **蓝牙不能当急停用。**
> 电机一动，和电机共用 5V 的 HC06 可能被电流冲击拉复位（7.3 节），
> 这时候你发的 `x` **根本到不了板子**，车会一直跑。
> **急停只信 KEY3（物理键）**，手始终放在电源开关上。
> 蓝牙的正确定位是"**车停着的时候改参数、读状态**"。

## 2. 命令总表

### 最常用的几条

| 命令 | 作用 |
|---|---|
| `a` | **启动**（进入循迹模式，等同按启动键） |
| `x` | **停车**（退出所有模式） |
| `c` | 查看转向增益与直道/弯道速度 |
| `c 70 60 300 250` | 设置：`kp=7.0` `kd=6.0` 直道 300 弯道 250 |
| `t` | 看一次循迹读数（哪几路压线） |
| `v` | 看整车状态（模式/故障/电压） |

### 循迹相关

| 命令 | 作用 |
|---|---|
| `t` | 单次读数：`hit: L3 L4` + `raw` + `err` |
| `d` | **连续显示**，每 100 ms 一行，手持模块扫线时用 |
| `z 20` | I2C 半周期（µs）。**默认 20 = 25 kHz，不要改小**（见第 7 节） |
| `s` | 切换 SCL/SDA 角色并探测（怀疑接反时用） |
| `f` | 扫描循迹模块 I2C 寄存器 |

### 速度环

| 命令 | 作用 |
|---|---|
| `r 300 300` | 速度闭环，左右各 300 mm/s（架空时用） |
| `r 0 0` | 停 |
| `g` | 查看速度环增益 |
| `g 80 800 90` | 设置 `kp=8.0` `ki=80.0` `ff=9.0`（都 ×10） |
| `o` | 开关 **50 ms 速度曲线**（目标/左/右/duty） |
| `l` | 查看角速度环增益 |
| `l 35 80` | 设置 `rate_kp=0.35` `yaw_kp=0.80`（×100） |
| `j` | 开关 **50 ms 角速度环曲线**（角速度目标 / 陀螺仪 / 差速） |
| `T` | 查看定角转弯参数（kp / acc / deg / v / brake / inner） |
| `T 200 250 95 0` | `kp=2.00` `acc=250°/s²` `deg=95°` `v=0`（kp ×100；传 `-1` 表示该项不改） |
| `T -1 -1 -1 -1 -1 130` | 只把 `inner`（内轮差速倍率）改成 1.30，让内轮多转 |
| `T -1 -1 -1 -1 60` | 只把进弯刹车相从 220 ms 改成 60 ms（车心往外溜时用） |
| `C` | 查看转弯计数 / 阈值 / 最后两次方向 / 盲走是否已触发 |
| `C 0` | 转弯计数清零（重跑一圈） |
| `C 5 1` | 至少 5 个弯、且最后两个都是右转 → 下一次丢线直接进盲走（写死航向） |
| `C 7 0` | 只按数量：至少 7 个弯，不限方向 |
| `w` | 开关 200 ms 编码器监控 |
| `p` | 电机/引脚/定时器/PID 内部状态 |

### 其他

| 命令 | 作用 |
|---|---|
| `i` | IMU 的 yaw / gyro |
| `q` | 测 IMU 实际帧率 |
| `e` / `k` | 编码器计数 / 定时器寄存器 |
| `b` | **按键识别模式**（只报告不动作，确认哪个键是哪路） |
| `y` | 遥测帧开关（**默认关**，开了会污染文本日志） |
| `h` | 帮助 |

## 3. 参数放在哪

### 能在线改的（不用编译）

| 参数 | 命令 | 默认值 | 含义 |
|---|---|---|---|
| 转向 P | `c` | **7.0** | 偏差 1 个探头 → 7.0°/s（×10 传入） |
| 转向 D | `c` | **6.0** | 误差变化率 → 预判弯道 |
| 直道速度 | `c` | **300** mm/s | |
| 弯道速度 | `c` | **250** mm/s | |
| 速度环 kp | `g` | 8.0 | |
| 速度环 ki | `g` | 80.0 | 已加积分分离，误差 >10 时不积分 |
| 速度环 ff | `g` | 9.0 | 前馈，实测 2685 duty / 300 mm/s |

> **注意**：`c` 和 `g` 的参数都是**乘 10 后取整**传入。
> `c 70 60 300 250` = kp 7.0、kd 6.0、直道 300、弯道 250。
> 传 0 表示"不改这一项"（`c 0 30 ...` 只改 kd）。

### 要改代码的（重新编译）

| 参数 | 位置 | 说明 |
|---|---|---|
| `CFG_STEER_KP_MAX` | `app_config.h` | 转向项限幅，默认 220°/s |
| `CFG_RATE_FF` | `app_config.h` | 差速前馈，由轮距自动算 |
| `CFG_RATE_KP` | `app_config.h` | 陀螺仪修正，默认 0.35 |
| `CFG_SPEED_I_BAND` | `app_config.h` | 积分分离带，默认 10 mm/s |
| 元素状态机参数 | `ctrl_fsm.c` | 环岛/十字/盲走的判定阈值 |

## 4. 调参总览

```
线位置 ──► 转向环(PD) ──► 角速度目标 ──► 差速 ──► 速度环(PI+FF) ──► 电机
   ▲                                              │
   └────────── 8 路循迹（100 Hz）◄────────────────┘
```

**两个环要分开调，顺序不能反：**

1. **先调速度环**（架空，用 `r` 命令）→ 保证"让你转多快就转多快"
2. **再调转向环**（上车，用 `a` 命令）→ 保证"看到偏了能拉回来"

**速度环没调好就调转向，等于在沙子上盖楼。**

### 当前实测结果

| 目标 | 稳态 | 误差 | 波动 |
|---|---|---|---|
| 100 | 99.6 | 0.4% | ±4 mm/s |
| 300 | 299.9 | 0.0% | ±4 mm/s |
| 500 | 499.9 | 0.0% | ±4 mm/s |
| 700 | 700.3 | 0.0% | ±4 mm/s |

**不需要再调。** 想验证的话：

```
① 车架空（轮子离地）
② o            ← 开速度曲线
③ r 300 300    ← 阶跃
④ r 0 0        ← 停
```

正常曲线：

```
[o] 300 280 279 2700 2690     ← 起步
[o] 300 377 368 3100 3080     ← 超调（约 25%）
[o] 300 301 300 2690 2685     ← 稳定
[o] 300 300 301 2685 2683
```

### 如果速度环出了怪问题

| 现象 | 检查 |
|---|---|
| 稳态差 5% 以上 | `p` 看 `iacc=`（积分项）。稳态误差大但 iacc 不涨 → 积分没工作 |
| 抖动 ±20 以上 | 测速窗口被改动了？应固定在 4 拍（20 ms） |
| 一侧快一侧慢 | 编码器左右装反 → `CFG_ENCODER_SWAP_LR` |

## 6. 循迹调参（重点）

### 6.1 先确认看到线

```
d              ← 连续显示
```

手拿模块在线上左右移动，应该看到：

```
L3 L4          ← 线在中间
L2 L3          ← 线偏左
L4 L5          ← 线偏右
none           ← 丢线
```

- 如果 `d` 全是 `none` → 模块没供电 / `z 20` 被改小了
- 如果名字和位置对不上 → 见第 7 节"位序"

### 6.2 转向环的四个参数

| 参数 | 作用 | 调大了会怎样 | 调小了会怎样 |
|---|---|---|---|
| **kp**（比例） | 看到偏差就打方向 | **画龙**（左右摆） | 慢慢漂出线 |
| **kd**（微分） | 看到偏差**在变大**就提前打 | 直道**发抖**、对噪声敏感 | 弯道**切外道、冲出去** |
| 直道速度 | | 快，但容易失控 | 慢，稳 |
| 弯道速度 | | 弯道容易冲出去 | 慢 |

**误差单位说明**：`err` 的 1.0 = **一个探头间距**（约 10 mm），范围 ±3.5。
所以头文件默认的 `kp=70` 表示"偏 1 个探头，就让车以 70°/s 转"。

> ⚠️ **先读这段（2026-11-21 现场实测更正）**
>
> 串口 `c` 命令的 kp 是**除以 10** 写进去的，而头文件默认值是 `CFG_STEER_KP = 70.0`。
> 现场回显：`c` → `steer kp=70.0 kd=6.0  vs=300 vc=250` —— **车实际跑的就是 kp=70**。
>
> 于是有两件事必须分开看：
>
> 1. **文档陷阱**：早期版本教 `c 60 60`，那是 kp=**6.0**，只有默认值的 1/11.7。
>    照抄会得到一个连弯都过不去的车（上限 21 °/s，最小转弯半径 682 mm）。已改。
>    正确写法：`c 400` = kp 40，`c 700` = kp 70 —— **kp 写百位**。
> 2. **但当前故障不是 kp 小**。kp=70 的转弯能力是够的（65 mm 半径都能过）。
>    弯道冲出去的主因是 **kd 太大**，下一节解释。

### 6.2.1 为什么 kd 不能大（8 路误差是离散台阶）

误差不是连续量：8 路探头、权重 -3.5…+3.5，相邻差 1.0，两路中点再补 0.5 ——
所以 `err` 只会以 **0.5 的整数倍**跳变。一次换位 `Δe = 1.0` 时：

| 项目 | 数值 |
|---|---|
| 误差低通 20 Hz，每 5 ms 走 38.6% | 第一拍 `Δe_f = 0.386` |
| 于是 `de = 0.386 / 0.005` | **77 pitch/s** |
| 乘默认 `kd=6` | **463 °/s**（远超 220 上限，直接封顶） |
| 弯中真正需要的角速度（250 mm/s，R=250 mm） | 只有 **57 °/s** |

结论：**默认 kd=6 时，D 项每次传感器换位都会把方向打满 2~3 拍（10~15 ms），
幅度是 P 项的 4 倍以上。** 它反映的不是"误差在变大"，是量化噪声。

这正好解释了故障现象：**直道 err 不变 → de=0 → D 静音 → 跑得很稳；
一进弯 err 不停跳变 → D 反复打满 → 车身猛顿/甩 → 线跑出视野 → 冲出去。**

想让 D 噪声不超过 30 °/s，需 `kd ≤ 30 / 77 ≈ 0.39`，即命令里 **`c ? 4` 以内**。
**kd 的可用区间是 0~10（CLI），不是 60~100。**

### 6.3 推荐调法：先直道，再弯道

#### 第一步：只调直道（关掉 D）

```
c 50 0 200 150     ← kp=5.0，kd=0，直道 200、弯道 150（慢速起步）
a                  ← 启动
```

观察直道：

| 现象 | 调法 |
|---|---|
| 走得很稳 | 加一档：`c 200 0 200 150` |
| **左右画龙** | `kp` 太大，退回上一档 |
| 慢慢往一边漂（偏得少） | `kp` 太小，继续往上加 `300` → `c 300 0 200 150` |
| 完全不走 | 线没检测到（`t` 确认） |

**找到"刚好不画龙"的 kp，然后退回 20%**（比如 80 画龙、60 稳，就用 60）。

> 这一步只验证"看到线会不会纠偏、方向对不对"。`c 50`~`c 80` 这一档的增益
> 连弯都过不去（见 6.2 节），**不要把它当成最终参数**，也不要因为"直道很稳"就以为调完了。
> 直道是否画龙，要等 kp 上到 300~700 之后再回头看。

#### 第二步：把 D 关掉，先看弯道变成什么样

```
c 700 0 250 200    ← kp 保持 70，kd=0，顺带把速度降到 250/200
```

（第 3、4 个参数写 0 表示不改速度；要动速度就写全 4 个数。）

| 现象 | 结论 / 下一步 |
|---|---|
| 弯里**明显变顺、不甩了** | ✅ 就是 D 项在捣乱 → 进第三步，kd 从 0 慢慢往回加 |
| 弯里**切外道但很平滑** | kp 不够或速度偏高：`c 700 0` 把弯道速度降到 180 |
| 直道开始**画龙** | kp=70 偏高，降：`c 500 0` → `c 400 0` |
| **还是冲出去**，且冲出去前 `v` 显示 `el=3`、`d` 的 `e` 掉回 0 | 是"丢线归零"，调参治不了 → 见 `09_corner_fix.md` 缺陷② |

#### 第三步：kd 只能在这个范围里加

```
c 700 5 250 200     ← kd=0.5
c 700 10 250 200    ← kd=1.0
```

| 现象 | 调法 |
|---|---|
| 加了 kd 弯道更贴、出弯不甩 | 保留，最多到 `c 700 15` |
| 加了 kd 车身开始**一顿一顿**（跟没加之前一样的抖法） | kd 太大，退回到上一档 |
| 直道发飘/高频抖 | kd 太大，回 0 |

**kd 上限 10~15（CLI）。** 超过这个范围只会把量化噪声放大成方向抖动，
原因见 6.2.1。旧版文档写的"加到 60~100"是错的，别用。

#### 第四步：提速

```
c 700 10 400 300   ← 直道 400，弯道 300（kp 保持百位写法，kd 保持个位）
```

| 现象 | 调法 |
|---|---|
| 跑得住 | 继续加：500/350 → 600/400 → 800/500 |
| 直道开始画龙 | 先降速度，再考虑降 kp |
| 弯道冲出去 | 降**弯道速度**（比降 kp 有效） |

**一次只改一档，每次跑两圈确认。**

### 6.4 常见组合（可作为起点）

| 场景 | `c kp kd vs vc` |
|---|---|
| 首次调试（很慢很稳） | `c 300 0 200 150` |
| 直道调好、弯道还不行 | `c 700 0 250 200` |
| 正常跑 | `c 700 10 400 300` |
| 竞速 | `c 700 15 800 500` |

> **kp 写百位**（`c 700` → kp = 700/10 = 70），**kd 写个位**（`c ? 10` → kd = 1.0）。
> 这两个的数量级不一样：kp 的默认值 70 能用，kd 的默认值 6.0 太大。
> 早期版本把两者写成同一个量级（`c 60 60`），既把 kp 砍到 1/11.7，
> 又把 kd 放大到量化噪声会打满方向的程度 —— 这是"弯道怎么调都冲出去"的完整原因。

## 6.5 进阶：角速度内环

> 直道和弯道都调顺了，还想让车在弯里更"贴"，就可以动这一环。

### 它在哪

```
线位置 ─► 转向 PD ─► 角速度目标 ─► 【角速度环】 ─► 差速 ─► 速度环 ─► 电机
                   w_ref          dv = FF·w_ref            ▲
                                       + kp·(w_ref - 陀螺仪) │
                                              ▲              │
                                          HWT101 ◄───────────┘
```

**它的作用**：转向 PD 算出"要以 120°/s 转"，角速度环负责**真的转到 120°/s**。
比例项 `w_ref` 只是"想转多快"，实际转多快由陀螺仪测出来并闭环。

不接陀螺仪也能跑（纯 FF），接了之后弯道会更准、抗侧滑。

### 先验证符号（**必须做，否则会暴振**）

```
① 车放桌上，架空
② j               ← 开角速度曲线
[cli] rate trace ON
③ 用手把车头【向右（顺时针）】转
```

看第二列（陀螺仪，右转为正）：

| 现象 | 结论 |
|---|---|
| 转动时**变正** | ✅ 符号正确，可以调 |
| 转动时**变负** | ❌ 符号反了 → 把 `app_config.h` 里 `CFG_GYRO_INVERT` 改成 **1**，重新编译 |

**符号错了这一环会变成正反馈，车身会剧烈抖动/暴振。** 所以在调 `rate_kp` 之前必须先做这一步。

### 调法

```
l                 ← 看当前值
[cli] rate kp=0.35  yaw_kp=0.80

l 35 80           ← rate_kp=0.35，yaw_kp=0.80（×100 传入）
l 60 -1           ← 只改 rate_kp=0.60，yaw_kp 不动（-1 = 不改）
```

> ⚠️ **只写一个数会把 `yaw_kp` 清成 0。**
> `l 80` 的效果是 `rate_kp=0.80` + **`yaw_kp=0.00`**（缺的参数按 0 解析，而 0 会被写进去）。
> 想只改 `rate_kp`，必须写 `l 80 -1`。
> 注意这跟 `c` 命令的语义相反：`c` 里 kp 传 0 表示"不改"，`l` 里传 0 表示"设成 0"。

| 参数 | 作用 | 默认 | 调大 | 调小 |
|---|---|---|---|---|
| `rate_kp` | 陀螺仪修正强度 | **0.35** | 弯道更贴线，但可能抖 | 更平顺但转弯偏软 |
| `yaw_kp` | 直道航向保持 | **0.80** | 直道更直，但过弯会"抢方向" | 直道容易漂 |

**`rate_kp` 的调法**（先架空、再上车）：

```
① j 打开，a 启动走直道
② l 60 -1        ← 从 0.35 加到 0.60
③ 观察：车身有没有高频抖动？
   抖 → 退回 0.45
   不抖 → 再试 l 80 -1
```

#### 先搞清楚这一环到底管什么（不然会白调）

前馈 `CFG_RATE_FF` 是按几何**精确标定**过的：

```
FF = (轮距/2) × π/180 = 75 × 0.01745 = 1.309 mm/s 每 °/s
被控对象 G = 2/轮距 (rad/s per mm/s) = 0.764 °/s 每 mm/s
FF × G = 1.000   ← 正好等于 1
```

**这意味着：只有前馈、`rate_kp=0` 时，稳态角速度就已经等于目标角速度。**
所以调 `rate_kp` 不会改变"稳态转多少度"，它只改变：

- 扰动抑制（轮子打滑、地面不平等）
- 追上目标的**快慢**（补偿速度环那 20~30 ms 的滞后）

如果你期待"加了 rate_kp 弯道就突然贴线"，大概率会失望。它的价值在
**载重、打滑、加速这些扰动场合**，不在稳态。

#### 环路增益：`rate_kp` 能加到多少

```
环路增益 L = rate_kp × G = rate_kp × 0.764
```

| `l` 命令写的值 | `rate_kp` | 环路增益 L | 预期 |
|---|---|---|---|
| 35（默认） | 0.35 | 0.27 | 很保守，几乎感觉不到 |
| 60 | 0.60 | 0.46 | 有轻微改善，安全 |
| 80 | 0.80 | 0.61 | **推荐上限区间** |
| 120 | 1.20 | 0.92 | 接近临界，注意高频抖 |
| 160 | 1.60 | 1.22 | 大概率开始抖 |

速率环的总延迟约 35 ms（IMU 100 Hz 零阶保持 5 ms + 速度环 30 ms），
对应能用到的带宽约 `1/(2π×0.035) ≈ 4.5 Hz`。**超过 L≈1 基本就是在赌。**

还有个天花板：`dv = 1.309×w_ref + rate_kp×(w_ref - ω)`。
`w_ref=220` 时前馈就吃掉 288，差速上限 `CFG_DV_MAX=420` 只剩 132 给修正量。
所以 `rate_kp` 加得再大，大弯里也还是会被斩在 420 —— 收益会饱和。

**`yaw_kp` 的调法**：

```
只影响 |误差| < 1.2 个探头时的直道航向保持
l -1 80          ← 只改 yaw_kp
直道还漂 → 加大到 1.2
过弯时车"抢方向"（不肯转） → 降到 0.5
```

### 什么情况下**不要**动这一环

- 陀螺仪符号还没验证过
- 速度环还在抖（先修内层）
- 直道还画龙（先修转向 P）

## 7. 已知问题（**接手前务必读**）

### 7.1 KEY1 按键坏了

板上三个按键，**KEY1（PC1）一直是低电平**，读不到按下动作。

| 键 | 功能 |
|---|---|
| KEY1 | 坏了，没功能 |
| **KEY2** | **启动 / 停止** |
| KEY3 | 急停 |

**更推荐用串口 `a` / `x` 启停**，比按键方便。

确认哪个键是哪路：发 `b` 进入按键识别模式（**只报告不动作**，安全），然后逐个按。

### 7.2 循迹 I2C 必须 25 kHz

模块的 I2C 从机是**软件模拟**的。实测：

| 速度 | 结果 |
|---|---|
| 200 kHz | 丢前 3 位（看起来像"只有 5 路能用""L1 显示成 L4"） |
| 50 kHz | 丢 1 位 |
| **25 kHz** | **正确** |

**所以 `z` 命令不要改成小于 20 的数。** 代码默认 `CFG_TRACK_I2C_HALF_US = 20.0f`。

因为一次读取要 1.6 ms，循迹读取降频到 100 Hz（每 2 拍读一次）。

### 7.3 蓝牙在电机动作时容易掉线

HC06 和电机共用 5V，电机启停的电流冲击会把 HC06 拉复位。

**证据**：MCU 日志里没有重启横幅，但蓝牙不再回数据。

**根治**：给 HC06 单独供电（手机充电器 5V，GND 与板子共地）。

**临时方案**：用 USB-TTL 有线调试，或者掉了就断电重启。

### 7.4 上电必须默认不动

按键上电瞬间被读成"按下"会导致车自己启动。已经修好：
- 按键初始化取**实际电平**（不是 0）
- 循迹状态机的 `EL_START` 要求**看到有效线才给速度**

**不要把这个改回去。**

### 7.5 遥测帧会污染日志

`y` 打开后，50 Hz 的二进制帧和文本日志抢同一个串口，日志会变成乱码/截断。
**调参期间保持关闭。**

## 8. 安全

| 项 | 说明 |
|---|---|
| **急停** | KEY3（粘滞，需复位）或串口 `x` |

| 首跑建议 | 速度 200/150，手放电源开关旁边 |

## 10. 出问题怎么查

| 现象 | 第一步 | 第二步 |
|---|---|---|
| 上电无任何输出 | 检查 5V / 3.3V 供电，按复位 | 串口线接对了吗（TX/RX 要交叉） |
| 有启动日志但没心跳点 | `ctrl_task` 没跑起来 | 看有没有 `[c] SLOW` |
| 车不动 | `v` 看 `mode` 和 `fault` | `fault` 非 0 会锁死电机 |
| 车乱冲 | 立即 `x` 或按 KEY3 | `v` 看 fault，`t` 看循迹 |
| 循迹全是 none | `t` 看 `raw` 和 `rc` | `rc<0` 是 I2C 失败；`raw=FF` 是没看到线 |
| 循迹名字错位 | `z 20` 确认速度 | 见 7.2 |
| 速度跟不上 | `o` 看曲线 | 见第 5 节 |
| 串口没反应 | 换个 COM 口试 | 蓝牙掉了（见 7.3），断电重启 |
