## 2. 方案：里程窗（保底）

### 2.1 原理

断口在赛道上的位置是**固定**的。用"自起跑以来的里程"判断：

```
丢线 且 里程在断口窗口内   →  盲走（直行穿过）
丢线 且 里程在窗口外       →  直角弯（定角转弯）
```

为什么这个可靠：

- 断口长 **1.68 m**，窗口可以开 ±300 mm，容错极大
- 定角转弯是原地转，`dist` 几乎不增长 → 转弯不会污染里程
- 不依赖任何传感器噪声

弱点（要认）：起跑位置变了要重标；打滑会累积误差；换赛道要重标。
**对固定赛道、固定起点的校赛，够用。**

### 2.2 改动（3 处，约 15 行，不碰现有逻辑）

**① `app_config.h` 加两个宏**

```c
/* 断口里程窗：自"首次看到线"起算的里程（mm）。
 * 标定后填。D1 <= D0 表示关闭这个功能。 */
#define CFG_GAP_WIN_D0_MM     0
#define CFG_GAP_WIN_D1_MM     0
```

**② `ctrl_fsm.c` 加一个静态变量，并在 EL_START 里记起点**

```c
static int32_t s_d_run0;      /* 首次看到线时的里程，窗口以此为原点 */
```

```c
case EL_START:
    ...
    if (line) {
        s_d_run0 = dist_mm;                 /* ← 加这一行 */
        enter(EL_STRAIGHT, dist_mm, yaw, tick_ms);
    }
    break;
```

**③ `ctrl_fsm.c` 的 EL_STRAIGHT 丢线分支，**最前面**（在 `CFG_LOSS_AUTOPILOT` 之前）插入**

```c
if (tick_ms - s_t_lost >= CFG_BLIND_ARM_MS) {

    /* 【里程窗】断口位置固定，用运行里程分流。优先级最高。 */
    if (CFG_GAP_WIN_D1_MM > CFG_GAP_WIN_D0_MM) {
        int32_t run = dist_mm - s_d_run0;
        if (run >= CFG_GAP_WIN_D0_MM && run <= CFG_GAP_WIN_D1_MM) {
            s_d_blind = dist_mm;
            enter(EL_BLIND, dist_mm, yaw, tick_ms);
            break;
        }
    }

    /* ↓ 原有逻辑不动 ↓ */
    if (CFG_LOSS_AUTOPILOT) { break; }
    ...
```

### 2.3 标定（10 分钟，两趟车）

1. 车摆在固定起点，`a` 起跑
2. 到断口丢线的那一刻，看 `[el]` 日志里的 `dist=`（或者丢线后立刻发 `v`）
3. 记下这个数 `D`，算 `run = D - 起跑时的 dist`（起跑时 `dist` 一般是个小值，记一下）
4. 填 `CFG_GAP_WIN_D0_MM = run - 300`、`CFG_GAP_WIN_D1_MM = run + 300`

| 位置 | `v` 里应该看到 | 说明 |

## 3. 方案：视觉（升级项）

代码里**已经接好了**：`ctrl_vis_gap()` 在 `ctrl_fsm.c` 挂了 4 处（STRAIGHT / TURN90 /
SEEK / CORNER），只要 K230 报 `VIS_FLAG_GAP`，整条路就通。

**只差一个从没做过的测量：**

```
在断口处跑 k230_simple.py，看控制台 near 的值
```

| 结果 | 处置 |
|---|---|
| `near = 0` | 直接把 `STRIP`/`MIN_BLACK` 微调一下，就能用 |
| `near > 0` | 调 `STRIP_X0/X1` 或 `MIN_BLACK`，让断口处恒为 0 |

视觉通了之后，里程窗**不要删**，留在代码里当 fallback（`CFG_GAP_WIN_D0/D1` 保留，
只是优先级让给 `ctrl_vis_gap()`）。
