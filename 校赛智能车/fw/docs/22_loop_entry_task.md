# 任务书：稳定切入六边形环岛

> 交给接手人。本文自包含，不需要读之前的对话。
> 代码：`fw/`（Keil MDK，STM32F407，双轮差速 + 8 路灰度 + 陀螺仪）
> 前置：盲走已经调通（`docs/21_blind_trigger_task.md` 已完成）。本任务是赛道上最后一个未解决的元素。

---

## 1. 任务一句话

**车从 1.5 m 盲走区出来后，要准确识别出六边形环岛入口并切进 `EL_LOOP_IN`，
然后在环里绕满 360° 从另一侧出来。**

现状是"有时候能进、有时候不进"，进了之后走得好不好也不稳定。

---

## 2. 赛道结构（这一段必须记牢）

```
... → 直角弯 ×7（最后两个是连续右转）→ 【1.5 m 断口，盲走】→ 六边形环岛 → 终点黑带
                                                            ↑ 本任务
```

**关键几何**：盲走区和环岛之间**几乎没有直道**。车从断口出来第一眼看到线，
那条线就已经是环岛的入口切线了。所以"出盲走"和"进环岛"必须是同一时刻的决策。

这也是为什么快判放在 `EL_BLIND` 的出口里，而不是等回到 `EL_STRAIGHT` 再判——
后者要多花 150 ms（`CFG_LOOP_ARM_MS`），车已经冲过切线了。

## 3. 现有实现（读这一节，避免重复造轮子）

### 3.1 入口判据：三重同意（已实现）

`ctrl_fsm.c` 的 `EL_BLIND` 出口（约 880 行）：

```c
int32_t run_mm = dist_mm - s_d_run0;

/* ① ② 先过"次数 + 里程"两关 */
if ((CFG_BLIND_NEXT_LOOP != 0) && (s_blind_lock != 0u) &&
    (run_mm >= CFG_LOOP_RUN_MIN_MM) && trk) {

    uint8_t l_e = (trk->left_edge  == 0) ? 1 : 0;
    uint8_t r_e = (trk->right_edge == 7) ? 1 : 0;

    if ((trk->count >= 3u) && (l_e || r_e)) {      /* ③ 形状 */
        side_loop = 1u;
        /* 偏置方向：单侧贴边 → 用贴边侧；双侧都贴（raw=E3）→ 用 err 符号 */
        ...
    }
}

if (++s_relock >= FSM_RELOCK_CYCLES) {
    s_finish_armed = 1u;                            /* 后面第一次全黑 = 终点 */
    if (side_loop) → enter(EL_LOOP_IN, ...)
    else          → enter(EL_STRAIGHT, ...)
}
```

| 条件 | 变量 | 当前值 | 含义 |
|---|---|---|---|
| ① 转弯次数 | `s_blind_lock` | — | 只有"数够 7 个弯 + 两连右"那次盲走才为 1 |
| ② 里程 | `CFG_LOOP_RUN_MIN_MM` | 8000 | 相对发车原点，低于此值不认 |
| ③ 形状 | `trk->count/left_edge/right_edge` | — | 一侧贴边 + ≥3 路，或双侧贴边 |
| ④ 开关 | `CFG_BLIND_NEXT_LOOP` | 1 | 1=六边形，2=圆形，0=关 |
| ⑤ 兜底 | `CFG_BLIND_LOOP_FORCE` | 1 | 2 = 降到"≥2 路就进" |

### 3.2 环岛绕行（已实现）

`ctrl_fsm.c` 的 `s_loop_tbl`：

```c
{ CFG_V_LOOP_HEX,  360.0f, 12000u }   /* 速度 180 mm/s，绕满 360°，超时 12 s */
```

状态链：`EL_LOOP_IN`（入口偏置 80 mm）→ `EL_LOOP_RUN`（绕行，累计 `s_yaw_acc`）
→ `EL_LOOP_OUT`（等线回中）→ `EL_STRAIGHT`

关键常量：`FSM_LOOP_ENTRY_MM=80`、`FSM_LOOP_BIAS=2.5`、`FSM_LOOP_SIDE_CNT=4`

### 3.3 `[tr]` 连续日志（已实现，本任务的主力工具）

进 `EL_BLIND` 自动开启，到 `EL_STOP`/`EL_START` 关闭，每 100 ms 一行：

```
[tr] el=6 raw=E3 cnt=3 err=0 yaw=-9 w=180 dist=9442
```

| 字段 | 含义 |
|---|---|
| `el` | 元素编号（5=盲走，6=环岛入口，7=绕行，8=出口，2=直道） |
| `raw` | 8 路原始字节，**bit0 = 最左**（编码见 §4） |
| `cnt` | 压线路数 |
| `err` | 加权误差（权重单位，满量程 ±3.5） |
| `yaw` | 航向（°） |
| `w` | 期望角速度（°/s） |
| `dist` | 累计里程（mm，发车原点=0） |

## 4. 8 路编码（判读 `raw` 必用）

`raw` 是 8 bit，bit0=最左、bit7=最右。**这是判断"线在哪、是不是环岛入口"唯一可靠的东西。**

| raw | 二进制 | 含义 |
|---|---|---|
| `18` | `0001 1000` | 居中（正常循迹） |
| `F8` | `1111 1000` | 左 5 路全亮 → 线在左 |
| `1F` | `0001 1111` | 右 5 路全亮 → 线在右 |
| `E3` | `1110 0011` | **左 2 路 + 右 3 路 → 环岛入口双线分叉**（主线+切线同时可见） |
| `FF` | `1111 1111` | 全黑（终点带 / 路口） |
| `00` | `0000 0000` | 丢线 |

**`E3` 是环岛入口的典型特征**，也是之前误判的根源：它既"左侧贴边"又"右侧贴边"，
用单一侧的判据都会失效，必须单独处理。

## 5. 已知实测数据（2026-11-23，这是唯一的基准数据）

```
[el] 5  err_lv=0   cnt=0 yaw=-8.x  dist=9xxx dt=7300 raw=00    ← 盲走中
[el] 6  err_lv=50  cnt=3 yaw=-9.6  dist=9442 dt=?    raw=E3    ← 环岛入口（成功进来了）
[el] 7  err_lv=-300 cnt=2 yaw=-32.6 dist=9524 dt=450 raw=3F    ← 82 mm 后
```

### 5.1 从这组数据能读出三件事

**① 入口确实是 `E3`（双线分叉）**
所以形状判据必须支持"双侧都贴边"这条分支，否则永远判不到。

**② 进来之后 82 mm 内右甩了 23°**（`yaw -9.6 → -32.6`），把线从右侧甩到了左侧
（`raw E3 → 3F`，`err +0.5 → -3.0`）。

**这一条已经修了**：`EL_LOOP_IN` 原来**无条件**加 `±FSM_LOOP_BIAS(2.5)`，
2.5 的权重相当于 `kp×2.5 = 175 °/s` 的转向，80 mm 内必然甩过头。
现在改成和 `EL_LOOP_RUN` 一致：

```c
s_o.e_bias = (line) ? 0.0f : (上一拍符号 ± FSM_LOOP_BIAS);
```

**③ 入口里程约 9442**（发车原点起算），这是标定 `CFG_LOOP_RUN_MIN_MM` 的依据。
现在设 8000，留了 1400 mm 余量。

### 5.2 但这组数据之后没有再验证过

`EL_LOOP_IN` 改成"有线跟线"之后，**没有新的实车数据**。
所以本任务的第一个动作不是改代码，而是**先跑一次，拿到新的 `[tr]` 数据**。

## 6. 排查流程（按顺序走，不要跳）

### 第 0 步：先跑一次，拿数据

不要先改代码。跑一圈，把以下三段日志完整保存：

1. 盲走最后 1 秒（`[tr] el=5` 若干行）
2. 盲走出口那一刻（`[tr] el=6` 的第一行，或 `[el] 6` 那行）
3. 环岛里（`[tr] el=7` 全部行，直到 `[el] 8` 或 `[el] 2`）

### 第 1 步：判断"有没有进去"

看 `[el]` 序列：

| 序列 | 结论 | 跳到 |
|---|---|---|
| `5 → 6 → 7 → 8 → 2` | 进去了，流程完整 | 第 3 步（优化走线） |
| `5 → 2`（没有 6） | **没切进去**，走了普通循迹 | 第 2 步 |
| `5 → 6 → 2`（没有 7） | 进了入口但 80 mm 内就退了 | 第 3 步 |
| `5 → 6 → 7` 卡住 12 s 才 `8` | 绕行超时（没绕满 360°） | 第 4 步 |

### 第 2 步：没切进去 → 逐条查三重条件

三重是 AND 关系，任何一条不满足都进不去。按这个顺序查（前两条有日志，最容易确认）：

**① `s_blind_lock` 是否为 1**

这是"数够 7 个弯 + 最后两次同向"那次盲走才有的标志。
如果盲走是**里程兜底**触发的（`docs/21` §6.3），`s_blind_lock` 可能是 0，
那么环岛判据的第一条就永远不过——**这是最可能的失效点**。

查法：看 `[turn]` 最后几行是不是 `#7/7 seq=[1,1]`，以及 `C` 命令输出里的 `blind_used`。

> ⚠️ 如果确实是兜底触发导致 `s_blind_lock = 0`，那环岛判据要把这一条从
> "必要条件"改成"检查项"——即：兜底进盲走的那次，也允许接环岛。
> 具体做法：把 `s_blind_lock` 换成 `s_blind_done`（两者在"计数触发"时都为 1，
> 但 `s_blind_done` 在兜底触发时也会置 1）。

**② 里程是否过了 `CFG_LOOP_RUN_MIN_MM`（8000）**

看 `[tr] el=5` 的 `dist` 列。如果出口时 `dist < 8000`，说明里程不够——
可能是发车位置比标定时靠后。按 §7.2 重新标定。

**③ 形状是否满足**

看出口那一拍的 `raw`：

| raw | 判定 | 处理 |
|---|---|---|
| `E3` / `F8` / `1F` / `C0` 等（一侧或双侧贴边，≥3 路） | 应该判到 | 若没判到 → 查 `trk->count` 是否 <3 |
| `18` / `0C`（居中，1~2 路） | 判不到 | 见 §7.1：车出断口时已经偏了 |
| `00` | 还没看到线 | 出口条件没满足，正常 |

### 第 3 步：进去了但走不好 → 查入口甩角

判据：`[el] 6` 与 `[el] 7` 两行的 `yaw` 差。

| yaw 差 | 结论 | 处理 |
|---|---|---|
| ≤ 10° | 正常（80 mm 走 10° 是合理的曲率） | 不用动 |
| 15~25° | 偏大，线会被甩到另一侧 | 降 `FSM_LOOP_BIAS` 到 2.0，或降 `CFG_V_LOOP_HEX` 到 150 |
| > 25° | 严重甩头 | 检查 `EL_LOOP_IN` 是否真的改成了"有线跟线"（§5.1 ②） |

同时看 `[el] 7` 的 `raw`：如果变成 `3F`/`0F`（线跑到另一侧），就是甩过头了。

### 第 4 步：绕行超时 → 查是否绕满 360°

`[el] 7` 停留 12 s（`CFG_V_LOOP_HEX` 那行的 timeout）才转 `[el] 8` = 超时踢出，不是正常绕完。

```
正常：exit_deg=360° 满足 → 退出，通常 8~10 s
异常：12 s 准时退出 → s_yaw_acc 没攒够
```

`s_yaw_acc` 没攒够的原因：
- 车在某个顶点**原地打滑**（角速度上不去），yaw 涨得慢
- 车被 `e_bias` 推着**直走**了一段（该转的地方没转）

判法：看 `[tr] el=7` 的 `yaw` 是否单调变化。正常应该一直往一个方向涨，
如果中间有"平着走"的段落，就是在那儿丢了边的引导。

## 7. 已知陷阱（都已踩过）

### 7.1 出断口时车已经偏了，`raw` 不是 `E3` 而是 `18`

盲走用的是"写死航向 = 发车方向 + 180°"。如果这个 180° 有一两度误差，
或者断口本身不是笔直的，车出来后线就不在预期位置。

后果：`raw=18`（居中）→ 形状判据不满足 → 进 `EL_STRAIGHT` 而不是环岛。

**对策**：如果反复出现，把 `CFG_BLIND_LOOP_FORCE` 改成 2（≥2 路就进）。
但这是"放宽"，会带来误判风险——只在确认"出断口必是环岛"的前提下用。

### 7.2 里程窗口标定不能用正方形

正方形闭环没有断口也没有环岛，无法标定。必须用真实赛道：

```
1. 把 CFG_BLIND_NEXT_LOOP 设 0（关闭环岛快判），避免干扰
2. 跑一圈，记 [el] 6 本应出现的位置（即出断口的 dist）
   如果没有 6，就用 [el] 5 退出时的 dist
3. CFG_LOOP_RUN_MIN_MM = 该里程 - 1400
```

### 7.3 双侧贴边（`E3`）时偏置方向是猜的

`E3` 时 `left_edge==0 && right_edge==7`，两个"单侧"条件都不成立，
只能退回用 `err` 符号。而 `err` 在那一拍可能接近 0，符号是**随机的**。

后果：偏置方向反了 → 车朝外圈甩 → 越走越远。

**对策**：如果实测发现"进去后往错误方向偏"，说明符号猜错了。
可以改成用"哪一侧的线路数更多"来判断（`cnt_left > cnt_right` → 环岛在左）。

### 7.4 六边形顶点处会丢线

六边形的六个角是尖的，车过顶点时 8 路可能瞬间看不到线。
此时靠 `e_bias`（2.5）兜住。如果顶点处甩出去，说明 `e_bias` 不够或速度太快：

```
先降 CFG_V_LOOP_HEX：180 → 150
若还甩：FSM_LOOP_BIAS 2.5 → 3.0
```

### 7.5 不要在环岛里开航向保持

`EL_LOOP_IN/RUN` 里 `yaw_hold = 0`。如果误开（改成 1），航向保持会和循迹抢方向，
表现为"环岛里车头一抽一抽的"。

## 8. 验收标准

跑 3 圈，每圈都满足：

| 项 | 标准 |
|---|---|
| 进入 | `[el] 6` 必须出现（3 圈 3 次，不能有"偶尔不进"） |
| 入口甩角 | `[el] 6 → [el] 7` 的 yaw 差 ≤ 15° |
| 绕行时间 | `[el] 7` 停留 8~11 s（不是 12 s 超时） |
| 出口 | 能走到 `[el] 8` 再回 `[el] 2`，不在 6/7/2 之间来回跳 |
| 出环岛后 | `[el] 2` 的 `err_lv` 在 ±150 以内（没有跑到边上） |

## 9. 不要做的事

1. **不要为了"能进去"直接把 `CFG_BLIND_LOOP_FORCE` 设 2**。
   那是放弃形状判断，会让半程任何 ≥2 路的地方都进环岛。先按 §6 逐条查。
2. **不要在 `EL_LOOP_IN` 里恢复"无条件偏置"**。那就是 23° 甩头的直接原因，
   已有实测数据支撑（§5.1 ②）。
3. **不要用正方形闭环验证环岛**。没有环岛，只会得到误导性结论。
4. **不要改 `exit_deg`（360°）来"让它在超时前退出"**。六边形少转一点会从入口旁边
   穿出去，看起来像"环岛里直冲"。真要快就降速度，不要降角度。

## 11. 实现状态（2026-11-24 18:30，第一轮）

### 11.1 实测诊断：不是判据参数问题，是"决策太早"

上一趟（`logs/run_181244.log`）出盲走那 5 行是决定性证据：

```
40.397  [el] 5 → [el] 2   cnt=2  raw=FC  dist=9531   ← 出口这一拍只有 2 路
40.502  [tr] el=3         cnt=3  raw=F8  dist=9547   ← 16 mm / 105 ms 后才 3 路
```

`EL_BLIND` 的出口只要 `line`（= `cnt>0`）连续 2 拍就成立，于是车在 **cnt=2** 时就退出去了。
而 §3.1 的形状判据是 `(trk->count >= 3) && (left_edge==0 || right_edge==7)` ——
**count 差一路**，`side_loop=0` → 回 `EL_STRAIGHT`，`[el] 6` 永远不出现。

三重同意的另外两条其实是满足的：
- ① `s_blind_lock`：本次盲走无论走"计数触发"还是"里程兜底"，触发体里都会置 1（代码里两条路共用一个 body）；
- ② 里程：出口 dist=9531 ≥ `CFG_LOOP_RUN_MIN_MM(8000)`；
- ③ 形状：**这一条因为取样太早而失败**。

### 11.2 已改（`ctrl_fsm.c` + `app_config.h`）

**出口决策改成"锁存形状再决定"**，新增三个静态量：

| 变量 | 作用 |
|---|---|
| `s_loop_seen` | 本段盲走是否见过环岛入口形状（锁存，见过就不再恢复） |
| `s_loop_bias` | 锁存到的偏置方向（由"哪一侧贴边"决定） |
| `s_d_firstline` | 出盲走第一次看到线时的里程 |

退出条件变成：

```c
shape_ready = s_loop_seen || (dist - s_d_firstline >= CFG_BLIND_EXIT_MM /*60*/);
if ((++s_relock >= FSM_RELOCK_CYCLES) && shape_ready) { 退出 }
```

- 形状一辨清（`count>=3` 且贴边）→ 2 拍后立刻退出，**延迟只有 20~80 ms（4~16 mm）**；
- 一直辨不清 → 最多再走 60 mm 就退（不会因为等形状冲出赛道）；
- 偏置方向用锁存值，不再用"出口那一拍"的 `err` 符号。

`CFG_BLIND_LOOP_FORCE` 保持 **1**（没有靠"放宽到 2 路"糊过去）。

### 11.3 顺带纠正：任务书 §4 的 raw 编码表是反的

`bsp_track.c` 实际变换是 `mask = reverse8(~raw)`，日志里的 `raw` 是原字节（0=压线）。

| raw | mask | 含义 |
|---|---|---|
| `E7` | `18` | 居中（正确） |
| `F8` | `E0` | **最右 3 路 → 线在右**（任务书写成"线在左"） |
| `1F` | `07` | 最左 3 路 → 线在左 |
| `E3` | `38` | 中偏右 3 路 = **正常直道**（任务书当成"环岛入口双线分叉"） |
| `FF` | `00` | 没有线（任务书写成"全黑"） |
| `00` | `FF` | 8 路全黑（任务书写成"丢线"） |

**判形状请用 `count / left_edge / right_edge`**（FSM 用的就是这三个，基于正确的 mask），
不要直接读日志里的 `raw`。详情见 `24_blind_walk_report.md` §6。

`dt=10500` 是**上一元素（EL_CORNER）的停留时间**，即车在 CORNER 里待了 10.5 s。

### 12.2 根因：断口前的"胶带残段"把车骗进了 EL_CORNER

- 判 CORNER 的条件是 `|err| > 2.0` 持续 50 ms。断口处胶带被斜切，接近时
  最后一段会跑到视野最外沿（实测 `raw=3F` = 最左两路、`err=-3.0`），正好满足。
- 一进 EL_CORNER，`kp_scale=1.2` → `w_ref = 55×1.2×3.0 ≈ 198 °/s`，
  车就绕着这段残线打转（四轮拖滑，`dist` 10.5 s 只涨 332 mm）。
- **致命点：盲走判据原来只写在 `EL_STRAIGHT` 的丢线分支里**，
  `EL_CORNER` 的丢线分支只有"视觉断口"和"直角弯"两条出路。
  所以车一旦被判进 CORNER，**盲走永远不会触发**，只能等
  `CFG_LOST_STOP_MS=10000` 的兜底停车。

> 这也解释了为什么 18:12 那趟能成：那次断口处是直接丢线（`cnt=0`），
> 走的是 STRAIGHT 的丢线分支，判据在正确的位置上执行了。

### 12.3 已改（`ctrl/ctrl_fsm.c`）

把断口判据从"写在某个 case 里"改成**三个调用点共用一套函数**：

| 函数 | 作用 |
|---|---|
| `blind_win_on()` | 窗口是否已标定（`max > min`） |
| `blind_win_hit(d)` | 当前里程是否落在窗口内（相对 `s_d_run0`） |
| `blind_cnt_ok()` / `blind_seq_ok()` | 转弯次数 / 最后两弯方向 |
| `blind_want(d)` | 计数同意 **或** 里程兜底（二选一即可） |
| `blind_go(d,yaw,t)` | 置 `s_blind_lock` + 写死航向 + 进 `EL_BLIND` |

三个调用点：

1. `EL_STRAIGHT` 丢线分支（原有）；
2. **`EL_STRAIGHT` 顶部：只要跑进 M 窗口就无条件进盲走**（不看线）——
   与已有的 `G` 里程窗（`s_gap_d0/d1`）完全同一套语义，只是换个数据源。
   这样残段再出现也不会把状态机带到 CORNER；
3. **`EL_CORNER` 丢线分支：进直角弯之前先问 `blind_want()`**，
   防止"先被判进 CORNER、再丢线"时直接转出赛道。

- 窗口 `7950..9950` 不动（窗口入口比丢线点早约 100 mm，断口是直的，无影响）。
- `CFG_BLIND_MIN_TURNS = 7`、`CFG_BLIND_REQ_DIR = 1` 不动。

### 13.5 环岛没进去的原因：把"间断"当成了"失败" ★

判据本身没问题（`10818` 那帧完全满足），问题在**累计方式**：

```c
if (line && count >= 4 && (贴边)) {
    if (s_t_edge == 0) s_t_edge = tick_ms;
    if (tick_ms - s_t_edge >= CFG_LOOP_ARM_MS /*150*/) { 进环岛 }
} else {
    s_t_edge = 0;          // ← 只要中间有一帧不满足就清零
}
```

入口形态实际是**三段**：`cnt=6（右贴边）→ 100 ms 后 cnt=4（两侧都不沾边）→ 再 100 ms 又 cnt=6`。
中间那 100 ms 一出现就把计时清零，于是永远凑不满 150 ms —— 和 `EL_SEEK`
当年"看见线就算找到"是同一类毛病：**要求"连续"，而物理信号是"断续"的。**

已改（`ctrl_fsm.c` + `app_config.h`）：

| 项 | 原来 | 现在 |
|---|---|---|
| 累计方式 | 必须连续 | **允许间断**：两次命中间隔 ≤ `CFG_LOOP_GAP_MS(200)` 就继续累计 |
| 丢线时 | 清零 | **仍然清零**（直角弯的特征就是"贴边后整片消失"，不能宽容） |
| `CFG_LOOP_ARM_MS` | 150 | **80**（入口宽黑只有约 100~200 ms） |

这样 `10818` 起算，约 80 ms 后（≈10900）就能进 `EL_LOOP_IN`，偏置方向由
`right_edge==7` 判为**右侧** —— 与地图上"六边形贴左侧线段、行进方向朝上"时环岛在右一致。

## 15. 分段调试模式（2026-11-24 新增，串口 `N` 命令）

### 15.1 为什么要它
整圈 55 s，环岛只占最后 12 s，一轮调试大部分时间浪费在等前面 7 个弯。
把车放"断口出口、刚接上线"的位置单独跑环岛，一段只要 **~25 s**，而且不受
前面 7 个弯的累积误差影响（发车姿态就是这一段的真实姿态）。

### 15.2 但它撞上一道闸
§13.5 加过 `CFG_LOOP_AFTER_BLIND`：**只有走过盲走才允许判环岛入口**
（防止直角弯的贴边被误判成环岛）。从断口出口起步时 `s_blind_done = 0`，
环岛永远不判。

### 15.3 用法

```
N 1       # 假装"盲走已走完"：允许判环岛入口（不受 a 影响，先发这个）
a         # 起步
```

`N`（不带参数）查看状态，`N 0` 关掉。**正常整圈跑必须保持 0。**

实现要点：`s_dbg_postblind` 是独立变量，**不能复用 `s_blind_done`** ——
后者在 `fsm_arm()`（发车）里会被清 0，那样"先 N 1 再按 a"就失效了。

### 15.4 车该放哪
断口结束、胶带重新出现的位置往后 **20~30 cm**，车头顺着胶带摆正。
从那里到六边形顶点约 1.1 m。

### 15.5 这一段的验收（与整圈相同）
1. `[el] 6` 出现在 `dist ≈ 10800 - 起点里程 ≈ 1100~1300`；
2. `[el] 7` 的 `yaw` 持续递减、累计到 360° 后退出（不是 12 s 超时）；
3. `[el] 8 → 2` 后能正常跟线。

环岛之后赛道上只剩终点一个黑带，这个位置最自然，也顺便兜住"盲走被跳过"的情况。
