## P0 · 直角转弯的稳定性（最高优先级）

> 用户原话：**"只有完美通过每个直角，才有后面节省时间的资本。"**

现状（基线那趟，7 个弯）：

| 指标 | 实测 | 说明 |
|---|---|---|
| 单弯耗时 | 850~1000 ms（均 921） | 全部踩在 1000 ms 线上 |
| 转角 | 平均 101.6°，极差 **7.0°** | 目标 ≤6°（文档 20 §9 的验收线） |
| 出弯 `err` | 全 ≤±50 | 合格 |
| 失败次数 | 6 次整圈里 1 次出问题（不是直角弯本身） | 但余量薄 |

**要做的：**

1. **把转角离散压到 ≤5°**。离散的来源是"入弯瞬间车速/姿态每次不同"，
   现在靠 `brake=80` 缓冲，但 300 mm/s 进弯 → 80 ms 只降到约 240 mm/s。
   候选：
   - 让进弯前直道末段自动减速（而不是靠刹车相硬等）；
   - 或把 `CFG_DV_MAX` 提高，让"转到目标角的速度"更一致（现在是速度环追不上）。
2. **加一次"转角闭环自检"**：转完如果 `|err| > CFG_TURN_FIND_ERR`（说明没对上），
   允许再来一个小角度补转（±15° 以内），而不是直接进 SEEK 蹭。这样可以
   把"转少了/多"的残余吃掉，比调整体 `deg` 更本质。
3. **验收**：连跑 3 圈，7 个弯的 `|done|` 极差 ≤5°、出弯 `err` ≤±50、零停车。

## P1 · 直角转弯的"连贯性"（不停车通过）

> 用户原话：**"每次都会停车确实会浪费不少时间，没有立即出发。"**

现状：`brake=80 ms` 先把车压到 `v_turn=60 mm/s`，再定角转，转完回直道。
单弯 921 ms 里，大约 350~450 ms 是"低速旋转"，其余是刹车相 + 起速。

**今晚已经改了一条（未烧录）**：转完如果 `|err| < CFG_TURN_FIND_ERR`（线已居中），
**直接回 `EL_STRAIGHT` 全速**，不再进 `EL_SEEK` 低速蹭。
预计每弯省 150~250 ms，7 个弯约 **1.4 s**，而且车不停顿。

**明天还可以继续试的：**

| 手段 | 预期 | 风险 |
|---|---|---|
| `v_turn` 60 → 90 / 120（转弯时保留更多前进速度） | 每弯 -80~150 ms | 切角变大、转角离散变大 → 必须先做 P0 |
| `brake` 80 → 40 | 每弯 -40 ms | 入弯前冲量不稳，转角开始飘（实测 0 时飘 37°） |
| 提前入弯（`P` 命令）重新启用 | 省"等丢线"的时间 | 这条道上 100% 误判（已实验证），除非重写判据 |
| 转弯时用 `w_ref` 前馈（角度环 + 差速前馈并联） | 旋转更快且不依赖速度环 | 需要调前馈系数 |

> ⚠️ 顺序：**先做 P0 再做 P1**。转角本身飘 ±7° 的时候加 v_turn，只会更飘。

## P2 · 盲走加速（在线可改）

> 用户原话：**"盲走确实可以走快一点，因为陀螺仪很准；走不直的话再给盲走加个积分项锁死角度。"**

现状：`B` 显示 `max=1900mm v=200mm/s`，实测 1612 mm / 8.33 s（194 mm/s）。

- 第一档：`B 0 250` → 省约 1.9 s；
- 第二档：`B 0 280` → 省约 2.6 s；
- 验证点：出口仍在 `dist≈9640` 看到线，`|err| ≤ 2.0`。

**如果走不直（横偏 > 60 mm）：**
给盲走加**航向积分项**——现在的盲走是 `w_ref = KP * (yaw_target - yaw)`（纯 P），
稳态误差会让车慢慢偏。加 `I` 项（对 `(yaw_target - yaw)` 积分）可以把它压到零。
注意：积分项要限幅（`±30 °/s`）并加抗饱和，否则一出盲走会甩。

## P5 · 调试效率（今晚已做）

> 用户原话：**"得来一个调速度更方便的串口命令，而不是每次都一个一个调。"**

```
S                                    查看全部速度
S <vs> <vc> <vblind> <vloop> <vturn> [brake]     一次改全部（0 = 该项不改）
```


无环岛命令）的做法。
