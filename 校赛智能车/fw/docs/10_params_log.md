# 10 参数台账

> 每跑出一组"能连续跑"的参数就记一行。
> **所有 `c` / `l` 参数都只在 RAM 里，复位或重新烧录就回到宏里的默认值** ——
> 所以这份表同时是"恢复手册"：车跑疯了、参数被改乱了，照着最后一行重发一次就回到已知状态。

---

## 当前基线（2026-11-21）

| 项 | 值 |
|---|---|
| 命令 | `c 550 0 300 300` |
| kp | 55.0 |
| kd | 0.0 |
| 直道速度 | 300 mm/s |
| 弯道速度 | 300 mm/s |
| 评价 | ✅ 目前最稳的一组，能连续跑 |

**2026-11-21 23:56 已写进 `app_config.h` 默认值**（`CFG_STEER_KP 55 / _KD 0 / _V_STRAIGHT 300 / _V_CORNER 300`）。
重新编译烧录后，上电就是这组，`c` 回显会直接显示 `kp=55.0 kd=0.0 vs=300 vc=300`，不用每次重发。
（在重烧之前，固件里还是旧默认 70/6/300/250，**必须手动发一次**。）

**手动恢复就一句：**

```
c 550 0 300 300
```

> 注意 vs = vc = 300，等于**弯道不减速**。这不是错——在 kp=55、kd=0 下
> 300 mm/s 的弯道余量够用。以后提速时再把这个比值拉开（见 08 文档 7.2 节）。

## 恢复流程（车状态乱了就照这个来）

```
① 断电重启（或按 KEY3 复位急停）
② c                    ← 看现在到底是什么参数
③ c 550 0 300 300      ← 回到基线
④ a                    ← 跑
```

## 参数速查

| 想改 | 命令 | 单位陷阱 |
|---|---|---|
| 转向 P / D + 两个速度 | `c <kp×10> <kd×10> <vs> <vc>` | **前两个 ÷10，后两个是 mm/s 原值** |
| 角速度环 `rate_kp` / 航向保持 `yaw_kp` | `l <rate×100> <yaw×100>` | **只写一个数会把 yaw_kp 清成 0，要写 `-1` 表示不改** |
| 定角转弯（台架验证） | `u <deg>` | 正 = 右转；到位/超时（1.5 s）自动停 |
| 盲走距离/速度 | `B <mm> <mm/s>` | 在线可调，不用编译。本图断口 1.68 m → `B 1830` |
| 速度环增益 | `g <kp> <ki> <ff>` | 一般不要动 |
