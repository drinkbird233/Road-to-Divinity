## 2. 提速杠杆（按"收益/风险"排序）

### A. 环岛速度 180 → 220~250（收益 ~2.2~3.4 s，**要重编**）

- 现状：`CFG_V_LOOP_HEX = 180`，2156 mm 走了 12.0 s。
- 到 220：9.8 s（省 2.2 s）；到 250：8.6 s（省 3.4 s）。
- **风险**：六边形每边只有 ~360 mm、折角 60°，速度高了会在顶点处"切角"甚至丢线；
  且环岛退出靠"累计 360°"，切角会让累计角变小 → 可能靠 12 s 超时退出（位置随机）。
- 验证点：`[el] 7` 必须 **<12 s 且不是靠超时**；每边出弯 `err` 不持续 >2.0。

### B. 盲走速度 200 → 250~280（收益 ~1.8~3.0 s，**在线可改**）

- 命令：`B 0 250`（距离预算不变，只改速度）。
- **风险**：盲走是纯开环，横偏只取决于航向（速度不影响横偏量），
  但**出口检测的延迟变短**：2 拍确认 = 20 ms，200 mm/s 是 4 mm，280 mm/s 是 5.6 mm，可忽略。
  真正的风险是"撞到胶带后处理时间变短"。
- 验证点：盲走出口仍能在 `dist≈9600` 看到线（`raw≠FF`），横偏 `|err| ≤ 2.0`。

### C. 直角弯 单弯 1.0 s → 0.8 s（收益 ~1.0~1.4 s，**在线可改**）

杠杆（按效果）：
1. `T` 命令把 `v_turn` 从 60 → 80：转得更快，但打滑比例上升、角度离散变大；
2. `brake` 从 80 → 60：省 20 ms/弯；
3. `CFG_DV_MAX` 提升（需重编）：转角速度上限，直接决定"最快能转多快"。

- **风险**：角度离散。目前 7 个弯的 `|deg|` 范围 4.5~9°，再快很容易飘到 15°+，
  出弯 `err` 也会变大（现在是 ±50）。
- 验证点：7 个弯 `|done|` 极差 ≤8°，出弯 `err@2` 全 ≤±100。

### D. 直道 / 弯道 300 → 330（收益 ~2.3 s，**在线可改**）

- 命令：`c 55 0 330 330`（直道和弯道一起提）。
- 历史：正方形场地上 350 会崩（入弯姿态变差、`err` 符号不可信），但这张图直道更长，
  330 值得试。
- **风险**：入弯前减速距离不够 → 进弯位置偏、直角弯触发变晚。
- 验证点：7 个弯的 `dist` 分散度不增大；`[turn] done` 仍在 95~110°。

### E. SEEK 缩短（收益 ~0.5~1.0 s，需重编）

- `FSM_RELOCK_CYCLES` 从 2 → 1（转完只要 1 拍居中就回直道）。
- **风险**：容易把"路过的一根反光线"当成找到了，回直道时姿态更差。

## 4. 执行顺序（一次只动一个，按风险从低到高）

**第 1 轮（全部在线可改，不用重编，5 分钟一轮）**

```
c 55 0 330 330      # 直道+弯道 300→330
```
跑 1 圈 → 看 7 个弯 `dist` 是否明显前移、`done` 是否还在 95~110°、环岛是否还进。

**第 2 轮**

```
B 0 250             # 盲走 200→250
```
跑 1 圈 → 看盲走出口 `dist` 与 `err`。

**第 3 轮**

```
T -1 -1 105 70 80 125 100    # v_turn 60→70
```
跑 1 圈 → 看 7 个弯 `|done|` 极差、出弯 `err`。

**第 4 轮（需要重编）**

- `CFG_V_LOOP_HEX` 180 → 220；
- 同时把环岛超时 12 s → 14 s（防止靠超时退出）。

**第 5 轮（可选，重编）**

- `CFG_DV_MAX` 扫 3 档（420 → 500 → 560），找"角度离散开始变差"的拐点；
- `FSM_RELOCK_CYCLES` 2 → 1。

## 6. 长期项（比调参数更有效）

1. **减打滑**：清洁轮胎、加配重、检查四轮气压/同轴度。
   这是唯一能同时改善"直角弯、环岛、S 弯"的杠杆，文档 `docs/20` §2 的结论仍然成立。
2. **环岛入口鲁棒性**：现在靠"连续压线 ≥5 路"，6 次里失败 1 次。
   加"里程 + 宽黑"双条件（顶点在起点后 1.05~1.1 m）可以把这类漏判去掉。
3. **盲走末段扫线兜底**：开环走 1.5 m，1° 误差 = 26 mm。
   走完预期距离仍不见线 → 左右各扫 ±20° 找线，比直接停车/超时好。

## 7. 现场提醒

- 提速后**环岛入口判据要重新确认**：速度变了，车在顶点的横向位置也变，
  `cnt≥5` 可能不再稳定（今天已经出现过 `FC` 和 `7C` 两种形态）。
- 每次改完速度，先跑 1 圈看状态序列完整，再连跑 3 圈看稳定性。
- 调试环岛用分段模式最省时间：车放断口出口后 20~30 cm → `N 1` → `a`。

### 8.3 执行顺序（一轮只动一个）

```
第 1 轮  S 0 0 250 0 0        盲走 200→250（最省事、风险最低）
```

### 8.4 每轮的验收线（任一条不过就退回）

- 停车 0 次；
- `[el] 6` 只出现 **1 次**，`[el] 7` **9~11 s 且不是靠 12 s 超时退出**；
- 7 个直角弯 `|done|` 极差 ≤ 8°，出弯 `[el] 2` 的 `err_lv` 全 ≤ ±100；
- 盲走出口能看到线（`err_lv` ≤ 2.0）；
