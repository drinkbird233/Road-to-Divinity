# 不停车转弯方案（交接文档）

> 目标读者：接手的工程师 / AI。本文不假设你读过之前的对话，所有结论都带数据来源。
> 代码位置：`fw/`（应用层在 `fw/app`、`fw/ctrl`、`fw/bsp`），编译用 Keil MDK，目标 STM32F407。

---

## 0. 一句话

把"丢线→刹停→原地转→找线"改成"提前入弯→边走边转→转完直接跟线"，
用陀螺仪保证角度、用 8 路保证位置。**但要先接受一个物理事实：这台车转弯快不了多少，能省的只有停顿。**

## 1. 硬件与已有代码

| 项 | 值 / 说明 |
|---|---|
| 主控 | STM32F407，FreeRTOS，控制节拍 5 ms，状态机 10 ms |
| 驱动 | 双轮差速，无舵机（不能做阿克曼） |
| 轮距 | **150 mm**（`CFG_WHEEL_BASE_MM`） |
| 编码器 | AB 双相，5 ms 窗口约 10 个脉冲（低速时量化噪声大） |
| 循迹 | 8 路灰度，**权重 −3.5 … +3.5**，`err = 压线路的权重平均值` |
| 陀螺仪 | 有，`yaw_ddeg`（0.1°）、`gyro_ddps`（0.1°/s） |
| 电机 | 12V 减速电机，`duty = 9.0 × v(mm/s)`，死区 60 duty（≈6.7 mm/s） |

### 8 路的关键编码（读日志必用）

`raw` 是 8 bit，**bit0 = 最左**，bit7 = 最右。例：

| raw | 二进制 | 含义 |
|---|---|---|
| `18` | `0001 1000` | 中间两路 → 居中 |
| `F8` | `1111 1000` | 左 5 路 → 线在左 |
| `1F` | `0001 1111` | 右 5 路 → 线在右 |
| `E3` | `1110 0011` | 左右都有 → 环岛入口分叉 |
| `FF` | `1111 1111` | 全黑（终点带 / 路口） |
| `00` | `0000 0000` | 丢线 |

## 2. 现状：为什么慢

### 2.1 实测数据（2026-11-24，正方形闭环，4 个直角弯）

```
[turn] done -94.8 deg
[turn] done -93.6 deg
[turn] done -93.1 deg
```

角度是准的（目标 95°，误差 <1.2°），但**每个弯耗时约 1.2 s**。

### 2.2 慢在哪：不是控制，是打滑

```
指令角速度（差速拉满 420 mm/s）：
  ω_理论 = 2 × 420 / 150 = 5.6 rad/s = 321 °/s
实际角速度：
  ω_实测 ≈ 94° / 1.2 s ≈ 78 °/s
打滑率 ≈ 1 − 78/321 = 76%
```

**轮子在空转，车只转到了指令的 1/4。** 这是速度环、PID、参数都救不回来的——它由轮胎与场地的摩擦系数决定。

### 2.3 由此得到的第一条硬约束

> 90° 转弯的物理下限 ≈ 90 / 110 ≈ **0.8 s**（假设把打滑率压到 30%）。
> 任何"让转弯变快一倍"的方案都不成立，除非先解决抓地。

## 3. 三种转弯模式的物理对比

设 `v` = 车心前进速度，`ω` = 实际角速度，则转弯半径 `R = v / ω`。

| 模式 | v | R | 车心横向位移 | 90° 耗时 | 备注 |
|---|---|---|---|---|---|
| **原地转** | 0 | 0 | 0 | 1.15 s | 现在的方案；准，但每次要刹停 |
| **圆弧转** | 150 | 86 mm | ≈86 mm（切角） | 0.9 s | 不停车，但要接受切角 |
| **大弧转** | 300 | 172 mm | ≈172 mm | 0.7 s | 切角超过视野，转完必丢线 |

`R = v/ω`，横向位移 ≈ `R(1−cos90°) = R`。

### 3.1 关键取舍

**"又快又不偏"不存在。** 要么慢（原地转），要么快但切角（圆弧转）。
切角本身不是问题——问题是切角超过 8 路视野（±35 mm）之后，转完看不见线。

所以圆弧半径的**上限**由视野决定：

```
R ≤ 35 mm ？ → 太苛刻，等于原地转
实测可用：R = 60~90 mm（切角 60~90 mm，转完线在视野边缘，SEEK 能救回来）
对应 v = 120~180 mm/s（ω=78°/s 时）
```

### 3.2 用"提前入弯"把切角补回来

等丢线再转，车头是正的，必须走完整 90° 圆弧，切角全落在路口外。
**在线还没丢、但已经偏到边缘时就开始转**，车头预先偏了 θ 度，圆弧只需走 90°−θ：

```
提前 θ=20° 入弯 → 转弯时间 缩短 22%，切角 减少约 1/3
```

这不是魔法，就是赛车走线里的"提前入弯"。代价是：如果判早了（其实是普通弯道），
车会提前转向，然后被循迹拉回来——**只会多摆一下，不会失控**。

## 4. 推荐方案：提前入弯 + 圆弧 + 陀螺仪定角

### 4.1 状态机

```
STRAIGHT
  ├─ |err| ≥ 2.5 且持续 30 ms   → TURN90（提前入弯，不停车）  ← 新增
  ├─ 丢线 + 数够弯 + 里程到位   → BLIND
  └─ 全黑持续 40 ms（武装后）   → STOP（终点）
TURN90
  ├─ 给固定 v = 130 mm/s 和 ±dv（不停车）
  ├─ 陀螺仪累计转角，到 90° 退出
  └─ 退出 → STRAIGHT（不要 SEEK，因为车一直在动、线就在旁边）
```

### 4.2 与现有代码的映射（**不需要重写**）

现有代码已经支持"不停车"，只是参数组合没用对：

| 需求 | 参数 | 说明 |
|---|---|---|
| 不停车 | `CFG_V_TURN` = **130** | 0 是原地转，130 是边走边转 |
| 不刹停 | `CFG_TURN_BRAKE_MS` = **0** | 220 会先停 220 ms |
| 目标角度 | `CFG_TURN_DEG` = **90** | 不停车时不需要 95 的斜插补偿 |
| 差速上限 | `CFG_DV_MAX` = **260** | 420 会打滑到 76%，260 打滑少、实际不一定更慢 |
| 内/外轮 | `inner` = **1.00**、`outer` = **1.00** | 先对称，等车心方向确定后再调 |

现场改（串口，不用重编）：

```
T -1 -1 90 130 0 100 100
```

### 4.3 唯一需要改的代码：提前入弯

`ctrl_fsm.c` 的 `EL_STRAIGHT` 里，在"丢线分支"**之前**加一段：

```c
/* 提前入弯：线偏到 2.5 以上且持续 30 ms → 认为前方是直角弯，不等丢线就开始转。
 * 阈值 2.5 对应"线在倒数第二路"，此时车头已经偏了约 20°，
 * 转弯只需再走 70°。 */
if (line && (absf(err) >= 2.5f)) {
    if (s_t_corner == 0u) s_t_corner = tick_ms;
    if ((tick_ms - s_t_corner) >= 30u) {
        enter_turn(EL_TURN90, dist_mm, yaw, tick_ms, err);
        break;
    }
} else {
    s_t_corner = 0u;
}
```

> 注意 `enter_turn(..., dir)` 的第 5 个参数是转向方向，正=右、负=左，直接传 `err` 即可。

### 4.4 实现状态（2026-11-24 已落地，与上面代码块的差异）

代码已加进 `ctrl_fsm.c` 的 `EL_STRAIGHT`（在"丢线"分支之前），
但**不是**照抄上面那段 —— 照抄会毁圈。补了四道闸，都在 `app_config.h`
的 `CFG_PRE_TURN_*` 里，现场用串口 `P` 在线改：

| 闸 | 为什么必须有 |
|---|---|
| **上膛**：线居中过（`|err| ≤ 1.0`）才允许触发 | 刚出弯回 STRAIGHT 的那几拍 `err` 就是 3.0（线在视野最外沿）。没有这道闸，它立刻被判"前方直角弯"，车连转两个 90°。 |
| **中止**：转过 50° 后线还在、`|err| < 1.5`、`cnt ≥ 2` → 回 STRAIGHT | 上面 §3.2 那句"判早了只会多摆一下"——**这句是错的**。`EL_TURN90` 里 `kp_scale = 0`，位置环是**关**的，车不会自己拉回来，只会硬转满 `deg`。赛道左上那段 45° 斜切会被硬转成 90°，斜着出赛道。 |
| **冷却 200 ms** | 防止出弯后抖动导致连续两次入弯。 |
| **环岛优先**：`s_t_edge != 0`（正在判环岛）时不许提前入弯 | 环岛入口的切线同样是"线偏到边上"，而且会持续很久。30 ms 的提前入弯会抢在 150 ms 的环岛判据之前开转，把环岛入口当成直角弯。 |

另外两处行为调整：

- **提前入弯跳过刹车相**：`brake` 再大也不停。否则默认 220 ms 会把
  "提前入弯"变成"提前停车 + 原地转"，比原方案更慢。
  要恢复"先停再转"，`P 0` 关掉即可。
- **转完直接回 STRAIGHT**（前提是线看得见），不进 SEEK ——
  SEEK 是"低速往前蹭着找线"，在不停车策略里反而会冲过下一个元素。

日志：`[turn] #n/N seq=[..] pre=1`。`pre=1` = 这一弯是提前入弯触发的；
`pre=0` = 还是老路（丢线后才转）。

> ⚠️ 必须配 §4.2 那组参数才成立：`T -1 -1 90 130 0 100 100`。
> 只开 `P 1` 不改 T，车会以 `v=0`、提前 20° 停下原地转，看起来比原来更差。

验证顺序（一次只动一件事）：

```
T -1 -1 90 130 0 100 100      # 第 1 步：先确认"不停车"形态（§6 第 1 步）
P 0                           # 跑 4 个弯，记 [turn] done 和 dt —— 旧路基线
P 1                           # 再跑 4 个弯，对比 dt 和 pre=1 的比例
```

`pre=1` 太少 → 阈值降到 2.2；普通弯也被提前转（弯里摆一下）→ 提到 2.8。

## 5. 参数清单（全部可在串口在线改，无需重编）

### 5.1 转弯（`T` 命令）

```
T <kp×100> <acc> <deg> [v] [brake] [inner] [outer]      -1 = 不改
```

| 参数 | 默认 | 单位 | 作用 | 调整方向 |
|---|---|---|---|---|
| `kp` | 2.00 | °/s per ° | 角度环比例 | 大→快但过冲 |
| `acc` | 250 | °/s² | 刹车曲线加速度 | 大→快但过冲 |
| `deg` | 95 | ° | 目标转角 | 不停车时用 90 |
| `v` | 0 | mm/s | 转弯前进速度 | **0=原地转，130=不停车** |
| `brake` | 220 | ms | 进弯刹车相 | **0=不停车** |
| `inner` | 1.25 | × | 内轮差速倍率 | 车偏右→加大 |
| `outer` | 1.00 | × | 外轮差速倍率 | 车偏左→加大 |

### 5.2 车心位移（最容易被误解的一组，务必看这里）

右转时 `vl = +dv·outer`，`vr = −dv·inner`：

```
车心速度 vc = (outer − inner)/2 × dv
```

| 关系 | vc | 车心走法 | 转完线的位置 |
|---|---|---|---|
| outer = inner | 0 | 纯旋转，车心不动 | 居中 |
| **outer > inner** | >0 | 前进着右转 | **线在左**（车往右去了） |
| **outer < inner** | <0 | 后退着右转 | **线在右**（车往左去了） |

**判读口诀：转完 `err_lv > 0`（线在右）→ 车偏左 → 把 `outer` 调大。**

每次只动 0.05。超过 1.15 会明显"边转边平移"。

### 5.3 提前入弯（`P` 命令，2026-11-24 新增）

```
P <on> [err×10] [hold_ms]        -1 或缺省 = 不改
```

| 参数 | 默认 | 作用 | 调整方向 |
|---|---|---|---|
| `on` | 1 | 总开关 | 0 = 回到"丢线才转" |
| `err×10` | 25（=2.5） | 触发阈值（权重单位） | 直角弯等丢线才转→降到 22；普通弯也被提前转→提到 28 |
| `hold_ms` | 30 | 持续多久才算数 | 误触发多→加大到 40~50 |

对应宏（改默认值才需要重编）：`CFG_PRE_TURN_ENABLE / _ERR / _HOLD_MS`，
以及四道闸 `_ARM_ERR / _COOL_MS / _ABORT_DEG / _ABORT_ERR`。

### 5.4 其他关键参数

| 宏 | 默认 | 说明 |
|---|---|---|
| `CFG_DV_MAX` | 420 | 差速限幅。**420 时打滑 76%，值得试 260** |
| `CFG_W_MAX` | 220 | 期望角速度上限，220 时已经追不到 |
| `CFG_STEER_KP` | 55 | 循迹 P（`c 550 0 300 300` 可改） |
| `CFG_RATE_KP` | 0.60 | 角速度环修正（`l 60 80` 可改，实测 1.32 会让 dv 饱和） |
| `CFG_V_STRAIGHT` | 300 | 直道速度 |
| `CFG_V_SEEK` | 180 | 找线速度 |

## 6. 调参步骤（严格按顺序，一次只动一个）

### 6.0 实车结果（2026-11-24，正方形闭环 边长≈550 mm，4 个直角弯）

| 配置 | 单弯 dt | 转完 err_lv | 结论 |
|---|---|---|---|
| 文档基线 `v=0 brake=220 deg=95` | 1181 ms | +300（偏 30 mm） | 每次都甩到另一侧，第 3 个弯丢线 |
| `brake=0`，其余同上 | 857 ms | ±50 | 刹车相是纯浪费，直接砍掉 |
| `brake=0 v=40 deg=130` | 737 ms（450~1300） | ±50 | 8 弯过完，但转角飘 37°、中途掉头一次 |
| `brake=80 v=40 deg=130` | 1021 ms | ±150 | 转角飘 **8°**，8 弯零掉头 |
| `brake=80 v=60 deg=130` | 964 ms（750~1050） | ±100 | 2 圈 8 弯、零停车零掉头 |
| **`brake=80 v=60 deg=105` + 方向锁（定案）** | **886 ms**（850~950） | **±100** | **3 圈 12 弯、零停车零掉头、转角 97~104°** |

三条被实车推翻的文档结论：

1. **§4.3 `err` 阈值 2.5 不成立**：真弯道丢线前 `err_lv` 只有 1.0~1.5，永远够不到 2.5；
   反而转完的残余误差有 ±3.0，会让提前入弯误判（实测把车带成左转 99° 下道）。
   → `CFG_PRE_TURN_ENABLE` 默认改 0。
2. **§4.2 "不停车不需要斜插补偿"不成立**：`v=130` 时 R=80 mm，转满 90° 线已在 ±35 mm 视野外。
   正确做法不是加大 `deg`，而是把"收手判据"从"看见线"改成"线压中间"（`CFG_TURN_FIND_ERR=1.0`），
   由它自动找角度。
3. **`v=0` 不是最快的**：两轮对转时打滑极重（ω=94 °/s），给 40 mm/s 前进分量后
   同一套差速跑出 203 °/s。想快先减滑，这条与 §2 的结论一致。

另外两条不属于转弯、但同样会毁圈：

- `CFG_BLIND_MIN_TURNS=5` 在正方形道上第 6 个弯就把车送进 `EL_BLIND`（锁死航向直冲）→ 改 200 关闭。
- `CFG_SEEK_TIMEOUT_MS` 800 太短（回中比"看见线"慢）→ 1200，且超时只要还看得见线就回 STRAIGHT。

**已经修掉的"180° 掉头"**（实测 + 用户现场确认）：`EL_TURN90` 里"线居中就收手"
原来只有下限（转过 ≥95°）、没有上限，车打滑冲过目标后会一直转，转到 ~180° 时
"来时的旧线"正好居中 → 被判成找到新线 → 整车掉头。现在：
① 收手窗口限定在 `[95°, deg+15°]`，超过就硬收手去 SEEK；
② 转完 150 mm 内再丢线不转弯（`CFG_TURN_COOL_MM`），改走 SEEK，
防止残余误差（±3.0）再触发一次转弯叠加成 200°+。

**`brake` 不能省成 0**：省了 220 ms 但进弯前冲量不稳定，转角飘 37°；
给 80 ms 后飘 8°。想让弯更快请先加 `CFG_V_TURN`（已试到 60）或减打滑。

**`deg` 不是越大越准**：deg 只决定"转到多少度收手"，剩下的偏差由 SEEK 在 180 mm/s 下补。
deg=130 → 实际 124~131°（斜骑在线上）dt 1018 ms；deg=105 → 实际 97~106°（贴 90°）**dt 887 ms**。
少转 25° 就是省时间，还更贴合。deg=95 是下限（转完线已在 ±35 mm 视野边缘）。

**转向方向的判据必须换掉**（实测掉头的第二个原因）：
原来用"丢线前最后一次 err 的符号"判左右。实测时序——
转完 `err≈0`（传感器压在线上），但车身仍斜着十几度 → 跑 100 mm 横向漂到线另一侧
（err 从 -0.5 变 +3.0）→ 下一个弯丢线时 `err_lv=+350` → 判成右转 → **方向反了**。
所以新增方向锁 `CFG_TURN_FORCE_DIR`（0 自动 / +1 右 / -1 左），现场用 `D` 命令切换。
固定方向的赛道（正方形、比赛道）一律锁死，这是整场最省事的一条可靠性保障。

**直道速度 300 是上限**：试过 350，第二个弯方向就反了（提速后入弯姿态变差，err 符号更不可信）。

### 第 1 步：确认"不停车"形态成立

```
T -1 -1 90 130 0 100 100
```

跑 4 个弯，检查：

- `[el] 12` 出现后**没有**明显的速度掉零（肉眼看车一直在动）
- `[turn] done` 在 `-88 ~ -92` 之间
- `[el] 2` 的 `err_lv` 在 `±150` 以内

**如果车在弯里"顿一下"**：说明 `v=130` 时内轮目标 `130−dv` 掉到负值附近，
电机反向有死区。把 `v` 提到 160，或把 `CFG_DV_MAX` 降到 220。

### 第 2 步：找"打滑最小"的差速

这是**最影响总时间**的一步，和直觉相反——差速越大不一定越快。

```
CFG_DV_MAX = 420 → 跑 4 个弯，记 [turn] 的 dt 平均值（现在约 1.2 s）
CFG_DV_MAX = 320 → 再跑，记 dt
CFG_DV_MAX = 260 → 再跑，记 dt
```

取 **dt 最小**的那一档。理论依据：

```
ω = 2·dv / d，但实际 ω 还取决于打滑率
dv 越大 → 打滑率越高 → 实际 ω 可能反而下降
```

判断是否在"打滑区"：看 `[tr]` 里的 `w` 列（期望角速度）。
如果 `w` 已经顶到 220 而车还是慢，就是在打滑，应该**降 dv** 而不是加。

### 第 3 步：修车心位置（`outer`）

看转完 `[el] 2` 的 `err_lv`：

```
err_lv = +150 ~ +300（线在右）→ 车偏左 → outer +0.05
err_lv = -150 ~ -300（线在左）→ 车偏右 → outer −0.05
err_lv = ±50 以内            → 成了，停
```

### 第 4 步：提前入弯（需要改代码）

按 §4.3 加那段代码，然后：

- 如果**普通弯道也提前转**（表现为弯里摆一下再回来），把阈值从 2.5 提到 2.8
- 如果**直角弯还是等丢线才转**，把阈值降到 2.2

## 7. 已知陷阱（踩过的坑，别再踩）

| 陷阱 | 现象 | 原因 / 对策 |
|---|---|---|
| **差速系数被 clamp 吞掉** | 调 `inner` 从 1.0 到 1.4 完全没反应 | `dvo/dvi` 若按 `CFG_DV_MAX` 截，`dv` 饱和时乘多少都被截回。**必须按 `CFG_V_MAX`(1000) 截** |
| **期望角速度追不到** | `[tr]` 里 `w=220` 但 yaw 只涨几度/秒 | 打滑。降 `CFG_DV_MAX`，不要加 `W_MAX` |
| **内轮目标落到 0 附近** | 弯里车"一个轮子不转" | `v` 太小时内轮 = `v − dv` ≈ 0。要么 `v` 提到 130+，要么接受原地转 |
| **SEEK 超时停车** | `[el] 13` 停 800 ms 后 `[el] 10` | 转完线在视野边缘（`err=3.0`），车一动就丢。根源是车心偏，先修 `outer` |
| **日志参数个数不匹配** | 出现 `seq=[0,536880852]` 这种鬼数字 | `app_log` 格式串的 `%d` 个数必须等于参数个数，否则读栈垃圾 |
| **环岛误触发** | 半程某处贴边就进环岛 | 环岛必须"三重同意"：转弯次数 + 里程 + 形状，缺一不可 |
| **全黑误判成路口** | 跑到终点不停 | 终点带和路口都是 8 路全压。盲走结束后武装标志，第一次全黑 = 终点 |

## 8. 日志解读（调车就看这几行）

| 标签 | 触发 | 关键字段 |
|---|---|---|
| `[el] n` | 状态切换 | `err_lv` 线误差（×100）、`cnt` 压线路数、`yaw` 航向、`dist` 里程、`dt` 停留时长、`raw` 8 路原始值 |
| `[turn] #n/N` | 进直角弯 | `seq=[a,b]` 最近两次转向方向（+1 右 / −1 左） |
| `[turn] done ±x.x` | 出直角弯 | **实际转过多少度**（只算 TURN90 期间，不含 SEEK）← 标定 `deg` 看这个 |
| `[tr]` | 盲走后每 100 ms | `raw` 形态、`cnt`、`err`、`w` 期望角速度 ← 判断打滑和环岛入口 |

### 读出"是否在打滑"

```
[tr] el=12 raw=FF cnt=0 err=0 yaw=-30 w=220 dist=500
                                   ↑ 期望 220°/s
下一条 100 ms 后 yaw 只涨了 8° → 实际 80°/s → 打滑率 64%
```

## 9. 验收标准

跑正方形闭环连续 8 个弯（2 圈），要求：

| 项 | 标准 |
|---|---|
| `[turn] done` 离散度 | 8 次的极差 ≤ 6° |
| 转完 `err_lv` | 全部在 ±150 以内（不贴边） |
| 单弯耗时 | ≤ 1.0 s（现在 1.2 s） |
| 是否停车 | 转弯期间 `speed_l/r` 不同时接近 0 |
| 丢线停车 | 全程无 `[el] 10`（除正常结束） |

## 10. 如果还是不够快

按影响从大到小排：

1. **抓地**：轮胎清洁/更换、增加配重、场地清洁。打滑率从 76% 降到 40%，立马快一倍——**这是唯一能实质性提速的手段**。
2. **降低转弯速度需求**：提前入弯角度加大（提前到 3.0），把 90° 转弯变成 70° 转弯。
3. **提高 `CFG_V_MAX` 与电机上限**：现在 `V_MAX=1000`，但 12V 电机实际也就 900 mm/s 左右，提升空间不大。
4. **换四驱/全向轮**：如果规则允许，差速两轮在 90° 直角处本身就吃亏。

**不要做的事**：把 `W_MAX` 加到 400、把 `CFG_DV_MAX` 加到 600。
两个都试过，结果是轮子空转更厉害、车更慢。
