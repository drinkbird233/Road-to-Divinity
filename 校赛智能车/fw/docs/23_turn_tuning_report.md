# 直角转弯调参报告（2026-11-24 实车）

> 本文记录"让 90° 直角弯又快又稳"这一轮的全部改动、依据和数据。
> 前置文档：`20_moving_turn_plan.md`（方案与物理推导，**其中 4 条结论已被本报告推翻**）。
> 测试环境：正方形闭环，边长约 550 mm（长短边交替 650 / 440 mm），4 个直角弯，地面为场地垫。

---

## 0. 一句话结论

单弯耗时 **1181 ms → 886 ms（快 25%）**，出弯横向偏差 **30 mm → ≤10 mm**，
连续 3 圈 12 个弯**零停车、零掉头、方向零反号**。
真正的提速点不是"转得更快"，而是 ①减打滑 ②少转角度 ③不再靠猜转向方向。

---

## 1. 起点与目标

| 项 | 起点（文档 20 的基线） |
|---|---|
| 转弯参数 | `v_turn=0 / deg=95 / brake=220 / inner=1.25 / outer=1.00` |
| 实测单弯 | 1181 ms，实际转 96°，出弯 `err_lv=+300`（车心偏 30 mm） |
| 症状 | 每次转完都甩到线的另一侧，第三个弯丢线 10 s 超时停车 |

目标：不停车过弯、单弯 ≤1000 ms、出弯 `|err_lv| ≤ 150`（文档 §9 验收线）。

---

## 2. 最终结果

参数：`deg=105 / v_turn=60 / brake=80 / inner=1.25 / outer=1.00`，直道 300 mm/s，方向锁 `D -1`（左转）。

| 项 | 结果 | 验收线 | |
|---|---|---|---|

| 连续里程 | 3 圈 12 弯无中断 | 2 圈 8 弯 | ✅ |

## 3. 八条改动（每条都带数据）

### 3.1 SEEK 出口加"回中"判据 ★

**现象**：转完线在视野最外沿（`err=±3.0`、`cnt=1`）也算"看到线"，50 ms 内就跳回 `EL_STRAIGHT`，
然后以 300 mm/s 全速去追 30 mm 偏差（`w_ref = 55 × 3.0 = 165 °/s`），一把扫过线冲到另一侧。

**改动**：`EL_SEEK` 出口从 `if (line)` 改为 `if (line && |err| < CFG_SEEK_CENTER_ERR)`（0.9）。
超时 800 → 1200 ms，且**超时后只要还看得见线就交回循迹**而不是停车。

### 3.2 转角收手判据 3.2 → 1.0，并补上限 ★★

**现象**：`CFG_TURN_FIND_ERR=3.2` 的含义是"线一进视野就收手"。实测 `deg` 设 95 和 105，
`[turn] done` **两次都是 96.3°** —— `deg > 96` 完全失效，转角被这条判据截断。

**改动**：`FIND_ERR = 1.0`（"线压在中间两路才收"），并新增上限 `deg + CFG_TURN_MAX_EXTRA_DEG(15°)`。

> ⚠️ 只加下限（"转过 ≥95° 才允许收"）是不够的：车打滑冲过目标后会一直转，
> 转到 **180°** 时"来时的旧线"正好居中，被判成"找到新线"就地停住 → **整车掉头**。
> 这是实车出现过的故障，也是本报告最重要的一条修正。

### 3.3 转完冷却 150 mm ★

**现象**：转完 40~130 mm 处残余误差有 ±3.0，会被丢线分支当成"前方又一个直角弯"，
再转一次叠加成 200° 以上。日志里表现为"两个弯只隔 50 mm"。

**改动**：`CFG_TURN_COOL_MM=150`，转完 150 mm 内再丢线不转弯，改走 `EL_SEEK`（低速 + 位置环）。

### 3.4 刹车相 220 → 80 ms

| brake | 转角离散 | 备注 |
|---|---|---|
| 220 | — | 基线，每弯多花 140 ms |
| 0 | **37°**（95~133°） | 省时间但前冲量不稳定，出现"转 130° 还找不到线 → 回转 → 盲走" |
| **80** | **8°** | 一致性最好 |

进弯那一刻车还有 300 mm/s，靠速度斜坡要 ~200 ms 才降到 `v_turn`，这段前冲量每次不同，
"需要转多少度"就跟着飘。**这 80 ms 买的是一致性，不是速度。**

### 3.5 转弯前进速度 `v_turn` 0 → 60 ★

| v_turn | 实测角速度 | 单弯 dt |
|---|---|---|
| 0 | 94 °/s（打滑 71%） | 1181 ms |
| 40 | — | 1021 ms |
| **60** | 200+ °/s | **886 ms** |

`v=0` 时两轮反向对转，内轮在跟地面较劲，打滑极重；给一点前进分量后轮子咬住了。
这与文档 20 §2"打滑 76%"的结论一致：**想快先减滑**。

### 3.6 目标转角 `deg` 130 → 105 ★

`deg` 现在的语义是"最多转多少"，剩下的偏差交给 SEEK 补。

| deg | 实际转角 | dt | 出弯姿态 |
|---|---|---|---|
| 130 | 124~131° | 1018 ms | 斜骑在线上 |
| **105** | 97~104° | **887 ms** | 贴近 90° |

**少转 25° 反而更快**：省下的旋转时间多于 SEEK 补偏差的时间。
`deg=95` 是下限（转完线已在 ±35 mm 视野边缘，SEEK 抓不到）。

### 3.7 盲走判定关闭（`CFG_BLIND_MIN_TURNS` 5 → 200）

正方形闭环没有断口，但代码"数够 5 个弯且最后两次右转 → 下一个丢线进盲走"的判据
在第 6 个弯就命中，航向被锁死直冲出去。**前面三趟的失败全栽在这。**
（该判据本身是对的，属于赛道专用逻辑，见 `21_blind_trigger_task.md`。）

### 3.8 转弯方向锁（新增，`D` 命令）★★

**现象**：转完虽然 `err≈0`（传感器压在线上），但**车身还斜着十几度**，跑 100 mm 就漂到线的另一侧；
到下一个弯丢线时 `err_lv` 变成 ∓3.5，于是"按 `err` 符号判左右"判反 → 整车掉头。

实测时序：

```
2.53s  转弯完成，err 回中 -50
3.79s  100 mm 后 err=+300      ← 车已漂到线的另一侧
4.11s  丢线时 err_lv=+350      → 判成"右转"，方向反了
```

**改动**：新增 `CFG_TURN_FORCE_DIR`（0 自动 / +1 右 / −1 左）+ 串口命令 `D`。
三处 `enter_turn()` 调用统一走 `turn_dir_from_err()`。固定方向的赛道不再靠猜。

## 4. 被实车推翻的四条原结论

| 原结论（文档 20） | 实测 |
|---|---|
| §4.3 提前入弯：`|err| ≥ 2.5` 触发 | 真弯道丢线前 `err_lv` 只有 **1.0~1.5**，永远够不到 2.5；反而转完的残余误差 ±3.0 会误触发。**已关闭** |
| §4.2 "不停车不需要 95° 斜插补偿" | `v=130` 时 R=80 mm，转满 90° 线已在 ±35 mm 视野外。补偿是必须的，但方式不是加大 `deg`，而是"转到线居中才收手" |
| §6 第 2 步"降差速能减少打滑" | `v=0` 才是打滑最重的配置（ω 仅 94 °/s）。先给前进分量，再谈差速 |
| §3.2 "判早了只会多摆一下" | `EL_TURN90` 里 `kp_scale=0`，位置环是关的，车不会自己回来，会硬转满 |

## 5. 仍然存在的问题（下一步方向）

| 问题 | 数据 | 代价/建议 |
|---|---|---|
| 打滑仍是主要耗时 | 886 ms 里约 500 ms 被滑移吃掉 | **清洁轮胎 + 加配重**，唯一能实质提速的 |
| `CFG_DV_MAX=420` 未扫 | `v=60` 之后打滑曲线变了，旧结论可能失效 | 需重编，扫 320 / 260 |
| 直道 300 mm/s 是上限 | 提到 350 → 第二个弯方向就反 | 提高转向增益或减打滑后再试 |
| 出弯航向仍差十几度 | `err=0` 但车身不平行，靠循迹慢慢拉 | 用 `ctrl_pred_slope()` 判"已平行"再交回（未实现） |

## 6. 日常使用

```
D -1        ← 跑左转（跑右转用 D 1）；上电后发一次
a           ← 起步
T           ← 查看当前转弯参数
c           ← 查看转向增益与直道/弯道速度
```

`D` 不加参数可查当前方向锁。默认 `0` = 自动判向，**忘了发也不会撞**，只是偶尔会在某个弯判反。

## 7. 换赛道怎么重新标定（按顺序，一次只动一个）

1. **先定方向**：`D 1` 或 `D -1`，跑一圈看 `[turn]` 的 `seq` 是否全程一致。
2. **标 `deg`**：看 `[turn] done` 与真弯角度的差。目标"实际转角 ≈ 真弯角度"，
   偏差大就改 `deg`（每个 5° 一档）。判据同时看 `[el] 2` 的 `err_lv`，落在 ±150 内即可。
3. **标 `brake`**：看转角离散度（`done` 的极差）。>10° 说明入弯前冲量不稳，加到 100~120。
4. **扫 `v_turn`**：40 → 60 → 80，取"dt 最小且离散度可接受"的一档。
5. **修车心**：转完后 `err_lv` 稳定偏一侧（>150）时，按文档 20 §5.2 调 `outer`
   （`err>0` 车偏左 → `outer` 加 0.05）。
