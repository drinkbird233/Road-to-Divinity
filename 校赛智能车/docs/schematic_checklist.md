# 智能小车扩展板原理图检查清单

配套文档：[`pin_plan.md`](pin_plan.md)  
核心板：STM32F407ZGT6 / LXBF407ZG-P1 V2.0  
使用方法：逐项勾选；任何一项不通过，先改原理图再画 PCB；在最后一页记录问题和处理结果。

---

## 0. 先查这 10 个关键网络

| 网络 | 应该连接 |
|---|---|
| MOTOR_L_PWM | PE9（TIM1_CH1） |
| MOTOR_R_PWM | PE11（TIM1_CH2） |
| MOTOR_L_IN1/IN2 | PE8 / PE10 |
| MOTOR_R_IN1/IN2 | PE12 / PE13 |
| MOTOR_STBY | PE14 + 10k 下拉 |
| ENC_L_A/B | PB6 / PB7 |
| ENC_R_A/B | PA6 / PA7 |
| OLED_SCL/SDA | PB8 / PB9，3.3V 上拉 |
| TRACK_SCL/SDA | PD3 / PD4，5V 上拉 |
| BT_TX/RX | PB10 / PB11 |

- [ ] 以上 10 组网络全部与 `pin_plan.md` 一致。
- [ ] 没有把 5V 网络接到 3.3V 网络，也没有把 VM 接到 5V。
- [ ] 所有网络名在原理图、PCB、代码宏中保持一致。

---

## 1. 核心板与排针

- [ ] 扩展板使用上下两组 **2×29P、2.54 mm 母座**，外排距 40.0 mm，与核心板实物/机械图一致。
- [ ] 核心板 74.5 × 43.5 mm 轮廓、安装孔、Type-C、SD 卡、BOOT0/RST 位置不干涉。
- [ ] 排针 1 脚方向正确，没有把背面丝印左右镜像画反。
- [ ] 每个网络名与核心板背面丝印一致（PA9/PA10、PB6/PB7 等）。
- [ ] 5V、3V3、GND 引脚全部连接，且没有把 5V 和 3V3 短接。
- [ ] 核心板 Type-C 5V 与扩展板 5V 之间有限流/跳线/二极管，不能同时硬并联。
- [ ] 3.3V 只由核心板 RY3420 提供；没有额外 3.3V 模块直接倒灌。
- [ ] 调试口 H1 的 PA9/PA10、SWDIO/SWCLK、RST、3V3、GND 可访问。
- [ ] 板载 SD、LCD FPC、按键、LED、USB 的引脚没有被扩展板再次使用。
- [ ] 排针焊盘/过孔与 2.54 mm 排针匹配，丝印有 1 脚标记。

---

## 2. MCU 引脚与冲突

- [ ] 每个 MCU 引脚只分配一个网络，没有重复。
- [ ] 使用引脚与 `pin_plan.md` 第 3 节完全一致。
- [ ] 未使用 PC8–PC12、PD2（SD 卡）。
- [ ] 未使用 PB3、PB5、PD11–PD13（LCD FPC）。
- [ ] 未使用 PA15、PE6（板载按键）。
- [ ] 未使用 PC13（板载 LED）。
- [ ] 未使用 PA11、PA12（Type-C USB）。
- [ ] PA13/PA14 仅用于 SWD，没有接其他器件。
- [ ] PA9/PA10 仅用于调试 USART1，没有和 HC06/K230 混接。
- [ ] BOOT0、NRST 有按键/测试点；BOOT1/PB2 保持低。
- [ ] 未使用 PH0/PH1、PC14/PC15、PB2。
- [ ] 所有 5V 输入信号只进入 5V 容忍脚（本方案已满足）。
- [ ] 所有网络名与代码宏一致（MOTOR_*, ENC_*, BT_*, K230_*, IMU_*, TRACK_*, OLED_*）。

---

## 3. TB6612 电机驱动

- [ ] 模块 2×8 排针顺序与实物丝印一致：PWMA/AIN1/AIN2/STBY/BIN1/BIN2/PWMB，VM/VCC/GND，AO1/AO2/BO1/BO2。
- [ ] PWMA → PE9，PWMB → PE11。
- [ ] AIN1 → PE8，AIN2 → PE10。
- [ ] BIN1 → PE12，BIN2 → PE13。
- [ ] STBY → PE14。
- [ ] VCC 接 3.3V，不接 5V。
- [ ] VM 接电池 VM（经保险丝/开关），不接 5V/3.3V。
- [ ] VM 旁有 100µF/25V + 100nF；VCC 旁有 100nF。
- [ ] STBY、AIN1/AIN2、BIN1/BIN2、PWMA/PWMB 均有 10k 下拉到 GND。
- [ ] STBY 没有被直接上拉到 3.3V，保留软件急停。
- [ ] AO1/AO2 → 左电机 M+/M−；BO1/BO2 → 右电机 M+/M−；丝印方向明确。
- [ ] 电机输出没有与 GND/5V 短路；连接器间距足够。
- [ ] TB6612 模块散热片/高度不与其他器件干涉。
- [ ] 电机线、编码器线分开走；电机线双绞。
- [ ] 3S 满电 12.6V 不超过 TB6612 VM 13.5V；没有用 4S。

---

## 4. 编码器

- [ ] 左编码器 A/B → PB6/PB7。
- [ ] 右编码器 A/B → PA6/PA7。
- [ ] 编码器 VCC 接 5V，GND 共地。
- [ ] 每个 A/B 线有 100Ω 串联 + 10nF 到 GND，靠近 MCU。
- [ ] 没有把编码器 5V 信号上拉到 3.3V；如需上拉，拉到 5V。
- [ ] 电机座 6-pin 定义 M+/M−/5V/GND/A/B 与电机实物线序一致。
- [ ] 左右编码器 A/B 没有接反到同一路；如接反，确认软件可修正。
- [ ] 编码器线与 PWM/电机线不平行长距离走线。
- [ ] 编码器 5V 电源有 100nF 去耦。

---

## 5. I2C 总线

- [ ] OLED SCL/SDA → PB8/PB9，I2C1，3.3V。
- [ ] OLED 总线上有 4.7k 上拉到 3.3V；若模块自带，预留 0Ω 跳线。
- [ ] 循迹 SCL/SDA → PD3/PD4，5V 软件 I2C。
- [ ] 循迹总线上有 4.7k 上拉到 5V；若模块自带，预留 0Ω 跳线。
- [ ] OLED 3.3V 总线和循迹 5V 总线完全分开，没有共用上拉。
- [ ] SCL/SDA 各串 22Ω（或 0Ω）保护。
- [ ] PD3/PD4 配置为开漏；上电默认释放为高。
- [ ] 循迹模块地址 0x12、OLED 0x3C 不冲突。
- [ ] I2C 走线短、远离电机线；有 GND 包地/伴地。
- [ ] 5V 循迹模块的 GND 与 MCU GND 共地。

---

## 6. 串口

- [ ] HWT101：PA2 = MCU TX → 模块 RX；PA3 = MCU RX ← 模块 TX；100Ω 串联。
- [ ] HC06：PB10 = MCU TX → 模块 RXD；PB11 = MCU RX ← 模块 TXD；100Ω 串联。
- [ ] K230：PC6 = MCU TX → K230 RX；PC7 = MCU RX ← K230 TX；100Ω 串联。
- [ ] 调试：PA9 = MCU TX → USB-TTL RX；PA10 = MCU RX ← USB-TTL TX。
- [ ] 所有模块 TX/RX 交叉，没有 TX 接 TX。
- [ ] HC06 STATE → PE15，10k 下拉；KEY 有跳线到 3.3V。
- [ ] HC06 供电 5V；其 TX 为 3.3V，PB11 可承受。
- [ ] HWT101 供电 3.3V（或按模块手册），其 TX 电平不超过 PA3 容忍范围。
- [ ] K230 5V/GND 各用两针，连接器旁有 470µF。
- [ ] 所有串口共地；没有地电位差。
- [ ] USART3/USART6 的 RX 有 DMA 连接（CubeMX 里配置）。
- [ ] 没有把 HC06 和 K230/调试串口接到同一组 TX/RX。

---

## 7. 电源与保护

- [ ] 电池 XT30 输入，正负极丝印/防反接明确。
- [ ] 5A 保险丝、电源开关、TVS/防反接器件按设计放置。
- [ ] 5V/5A 模块输入/输出电容足够；空载输出先调到 5.0V。
- [ ] 5V 供给核心板、K230、HC06、HWT101、循迹、编码器、蜂鸣器。
- [ ] 3.3V 由核心板 RY3420 提供，供给 OLED、TB6612 VCC、上拉。
- [ ] 3.3V 总电流估算 < 核心板 RY3420 能力；若接近上限，加 3.3V 模块并隔离。
- [ ] Type-C 5V 与扩展板 5V 不会同时倒灌。
- [ ] VM、5V、3.3V 对 GND 没有短路；上电前用万用表测。
- [ ] 每个电源轨有测试点/电源 LED。
- [ ] 电机地、电源地、信号地单点汇合；没有地环路。
- [ ] K230、TB6612、5V 模块、3.3V 附近有足够 bulk cap。
- [ ] 电解电容极性正确，耐压 ≥ 2× 工作电压（VM 用 25V）。
- [ ] 5V/3.3V 走线宽度足够（5V ≥1.5 mm，3.3V ≥0.5 mm，VM ≥2 mm）。
- [ ] 电池分压接在保险丝后、开关前/后按需求；PA4 不超过 3.3V。
- [ ] 所有外部接口有 ESD/TVS 或至少串联电阻（按需要）。

---

## 8. ADC 与人机接口

- [ ] PA4 分压 47k/10k，100nF 到 GND；12.6V 时 <3.3V。
- [ ] 分压电阻靠近 ADC，走线短；远离电机噪声。
- [ ] 蜂鸣器 NPN 基极 1k，续流二极管，5V 供电。
- [ ] KEY1–KEY3 10k 上拉 + 100nF，按下接地。
- [ ] LED1/LED2 1k 限流，高电平亮。
- [ ] 所有按键/LED 丝印功能明确。
- [ ] 预留 BOOT0/RST 按键或测试点，不被外壳挡住。
- [ ] 调试串口/USB-TTL 接口可访问。

---

## 9. 连接器与机械

- [ ] PH2.0 1 脚有丝印/方焊盘；防插反。
- [ ] 电机座、循迹、OLED、HC06、HWT101、K230 连接器定义与 `pin_plan.md` 第 7 节一致。
- [ ] 电池不用 PH2.0；用 XT30。
- [ ] K230/HC06 天线区域没有铺铜/金属遮挡。
- [ ] 核心板 Type-C、SD 卡、BOOT0/RST、SWD 不被扩展板挡住。
- [ ] 扩展板安装孔与车盘匹配；高度避让 TB6612/电源模块/电解电容。
- [ ] 连接器位置便于插拔，不互相干涉。
- [ ] 板框 80×50 mm 或按车盘调整；四角倒圆/安装孔。
- [ ] 丝印标注 5V/3.3V/VM/GND、TX/RX、电机左右。
- [ ] 有 1 脚/极性/高压警告标识。

---

## 10. 上电前与上电顺序

- [ ] 裸板测 VM-GND、5V-GND、3.3V-GND，无短路。
- [ ] 不装核心板，先给 5V 模块输入，调输出 5.0V。
- [ ] 装核心板，测 3.3V；摸核心板/稳压器温度。
- [ ] 只接调试口，能识别 SWD，能烧录。
- [ ] 串口打印正常；USART1 115200。
- [ ] 接 TB6612，STBY=0 时电机不转；STBY=1、低 PWM 时方向正确。
- [ ] 编码器正转计数增加，反转减少；左右轮方向正确。
- [ ] I2C 扫描到 0x3C 和 0x12；OLED 显示正常；循迹 8 路有变化。
- [ ] HC06 能配对，115200 收发正常；STATE 检测正常。
- [ ] HWT101 有数据，yaw 变化正常。
- [ ] K230 串口有帧，超时保护生效。
- [ ] 电池电压 ADC 读数与万用表一致（误差 <0.2V）。
- [ ] 急停/失联/低电压时 STBY=0，电机停。

---

## 11. 常见错误（重点看）

- [ ] 核心板排针左右镜像画反（背面丝印 vs 正面视图）。
- [ ] TB6612 模块排针顺序按位置猜，没按丝印。
- [ ] HC06/K230/HWT101 的 TX/RX 没交叉。
- [ ] 5V 循迹模块和 3.3V OLED 共用 I2C 总线/上拉。
- [ ] 编码器 5V 信号上拉到 3.3V。
- [ ] TB6612 输入没有下拉，上电电机抖动。
- [ ] STBY 直接接 3.3V，失去软件急停。
- [ ] Type-C 和扩展板 5V 同时供电。
- [ ] 3.3V 模块与核心板 3.3V 直接并联倒灌。
- [ ] 用了 SD/LCD/按键/LED 的占用引脚。
- [ ] 电池分压超过 3.3V。
- [ ] K230 5V 只用一个 PH2.0 针，压降/发热。
- [ ] 电机地与信号地没有单点汇合，编码器计数乱跳。
- [ ] 电解电容极性/耐压错误。
- [ ] 忘记 BOOT0/NRST 可访问，无法下载。
