# 简易数字示波器 · 项目说明

> 平台：STM32F103C8T6（立创简易示波器板）· 1.8" ST7735S SPI TFT
> 工具链：STM32CubeMX + CMake/Ninja + arm-none-eabi-gcc，ST-Link(SWD) 下载
> 工程路径：`d:\tool\stm32cubeide\STM32halcode\Project1`

---

## 一、功能

- **波形显示**：ADC 采 300 点 → 软件触发对齐 → 左侧区域画波形（稳定不滚）
- **频率测量**：比较器方波进 PA6，TIM3 输入捕获测周期 → 显示频率（Hz / KHz）
- **峰峰值显示**：一帧内的电压峰值 → 屏上显示 `x.xxV`
- **方波信号源**：TIM2_CH3(PA2) 输出 1K/2K/4K 方波，占空比可调（可自检）
- **交互**：旋钮缩放时间轴、按键调占空比/频率/输出开关、KEYD 暂停波形
- **LED 指示**：PC14/PC15

## 三、CubeMX 关键配置

| 外设 | 配置 |
|---|---|
| RCC | HSE 8M × PLL9 = **72MHz**；ADC 时钟 PCLK2/6 = 12MHz |
| SPI1 | Master、8bit、MSB、**CPOL=High / CPHA=2Edge（模式3）**、NSS 软件、预分频4 → 18MHz，只占 PA5/PA7 |
| ADC1 | **连续转换 Enable**、软件触发、采样时间 239.5 cycles、通道 IN3 |
| DMA1_CH1 | ADC→RAM，**Normal 模式**（非循环），半字对齐 |
| TIM2 | PWM CH3，PSC=71 / ARR=999 → **1kHz**，PA2 |
| TIM3 | 输入捕获：**PWM 输入/复位模式**，TI1FP1，上升沿；**PSC=71（1MHz 计数）** |
| NVIC | EXTI4、EXTI15_10、DMA1_CH1 使能 |
| TIM1 | 不用（早期方案用定时器触发 ADC，后改为连续转换，已禁用）|

## 四、软件架构

```
Core/Src/main.c        主流程：初始化 → 采集 → 触发 → 画波形 → 刷 UI
Core/Inc/main.h        数据模型 struct Oscilloscope + 按键常量
Hardware/Src/tft.c     ST7735 显示层：画点/线/矩形、显示字符/汉字、drawCurve、UI 布局
Hardware/Src/tft_init.c ST7735 底层：SPI 收发、寄存器、TFT_Init 初始化序列
Hardware/Inc/font.h    中英文字库（ASCII + 12/16/24 点阵汉字）
Hardware/Src/keys.c    按键扫描 Key_Sacnf / Key_Handle / KEYD_SCAN + 旋钮/按键 EXTI 回调
```

### 数据流

```
TIM 波形方波 → 比较器 → PA6 ── TIM3 输入捕获 ──→ gatherFreq（频率）
PA3 模拟信号 → ADC1(连续) → DMA(300点) → RAM
                              │ DMA 完成中断
                              ▼
                      HAL_ADC_ConvCpltCallback：置 showbit=1，停 DMA
                              │
   主循环检测 showbit ────────┘
   → 换算电压 voltageValue[]
   → 求峰值 vpp、最小值 min
   → 找触发点 Trigger_number（首个上穿阈值）
   → 逐点映射到屏幕 y，drawCurve() 画线
   → TFT_ShowUI() 刷新频率/峰值/占空比文字
   → HAL_ADC_Start_DMA() 重启下一帧
```

### 触发/缩放原理

- **触发**：在 300 点里找「第一次从阈值下方上穿」的位置作起点，波形左端锁在固定相位 → 不滚动。
- **缩放**：KEYA/KEYB(旋钮) 切换 ADC **采样时间**（239.5↔71.5↔55.5↔41.5↔28.5 cycles）→ 采样率变化 → 每点代表的时间变化 → 波形横向伸缩。
- **显示**：波形区在 x 0~99、y 30~80；右侧 x100~159 放文字信息。

## 六、打过的坑（调试经验）

1. **newlib-nano 浮点 printf**：`--specs=nano.specs` 默认砍掉 printf 浮点 → `sprintf("%1.2fV", vpp)` 输出空。加链接选项 `-u _printf_float` 解决。
2. **输入捕获溢出**：TIM3 PSC=0（72MHz）时，16 位计数器最大 65535 → 低于 **1098Hz** 的信号周期会溢出，1kHz 被误读成 11kHz。改 **PSC=71（1MHz）**，最低可测 ~15Hz。
3. **波形只有横线没竖边**：逐点画不连点，方波的垂直跳变丢了 → 必须**连点成线**。
4. **刷新撕裂/闪烁**：边画边被 DMA 覆写 → 先**快照**这一帧的点；整屏两趟刷（先清屏再画）会闪 → 改**逐列一次写（背景+波形一起）**。
5. **ST7735 全白**：初始化没生效时默认全白；填白色 + 边缘边框容易被裁 → 用**蓝色底**才看得出通没通。
6. **面板偏移/绿线**：ST7735 内部显存 132×162，可见区 160×128，不同批次起点不同，边缘会多一条杂色线（不影响使用）。
7. **ST-Link 卡死**：VS Code 下载报 `could not connect (error 138)` / GDB `vMustReplyEmpty: timeout` = `stlinkserver.exe` 卡死 → `taskkill /F /IM stlinkserver.exe`，或直接用命令行烧。
8. **中文编码**：字库 `Index[]` 是 GBK 字节，靠 memcmp 匹配字符串 → 含中文的文件必须也是 GBK，否则中文不显示。
9. **电压标定**：走板上前端用 `voltage = 5 - 2*V`；直连 PA3 用 `voltage = adc*3.3/4095`（`OSC_FRONTEND` 宏切换）。
10. **定时器触发 vs 连续转换**：最终采用参考工程的**连续转换**方案（缩放靠改采样时间）。

- **中断优先级**怎么安排的？ADC 完成回调在哪个上下文执行？

- `volatile` 在 `struct Oscilloscope` / `gatherFreq` 上为什么需要？
- newlib-nano 为什么没有浮点 printf？怎么开？
