## 开发时间线

1. **LED**：PC14/PC15 闪烁 → 改常亮（低电平点亮，`GPIO_PIN_RESET`）。
2. **按键**：PB13/PB14 EXTI → 控制 PC15 翻转。
   - 坑：上拉 + 按键接 GND 时，**按下是下降沿**，配成上升沿会松手才触发。
3. **ADC 采样**：PA3。先设计成 **TIM1 触发 + DMA 循环**（100kHz），后改为参考工程的**连续转换**方案。
4. **输入捕获测频**：PA6，TIM3。PA6 只有 TIM3_CH1 能硬件捕获 → 和 ADC 触发抢 TIM3，于是把 ADC 触发挪走（先 TIM4、后改连续转换）。
   - 坑：**TIM4 引脚(PB6/7/8/9)被 TFT+KEYD 占满，本板不可用**。
5. **TFT 显示**：ST7735S，SPI1(PA5/PA7) + PB5~PB8。
   - 从"蓝底白框"验证通断 → 对齐测试 → 波形显示。
6. **OLED 支线**：顺手把一份波特律动 OLED 库整理成可移植的 SSD1306 版本，存到 `D:\默认存储\干活\软件\hal库代码\OLED代码\OLED_SSD1306\`。
7. **完整示波器**：照参考工程"综合案例"复刻 —— 网格 UI + 中文字库 + 频率/峰值显示 + 方波输出控制 + 旋钮 + 按键。
   - 显示层（含中文）**逐字节拷贝**参考工程（保持 GBK 编码），应用层自己重写（无中文，UTF-8）。

## 关键技术决策

| 决策 | 选择 | 原因 |
|---|---|---|
| ADC 采样 | 连续转换 + DMA(Normal, 300点) | 贴合参考工程；缩放靠改采样时间 |
| 测频 | TIM3 输入捕获复位模式，PSC=71 | 复位模式直接得周期；PSC 防溢出 |
| 显示层 | 全部拷贝参考工程（GBK） | 中文字模靠字节匹配，自己写 UTF-8 会不显示 |
| 电压标定 | `OSC_FRONTEND` 宏切换 | 走前端 `5-2V` / 直连 `adc*3.3/4095` |
| 下载 | 命令行 STM32_Programmer_CLI | VS Code 那条路（stlinkserver）老卡死 |

## 遇到的坑 & 解法（都验证过）

1. **触摸屏全白**：ST7735 未初始化时默认全白。填白+边缘框会被裁 → 换蓝底才看得出。
2. **只有横线没竖边**：逐点画不连点 → 改**连点成线**。
3. **闪烁**：清屏+画两趟 = 黑↔波形闪 → 改**逐列整列重画（背景+波形一起）**。
4. **顿一下/撕裂**：边画边被 DMA 覆写 → 先**快照**这一段数据再画。
5. **峰值不显示**：`--specs=nano.specs` 缺浮点 printf → 加 `-u _printf_float`。
6. **1kHz 显示成 11kHz**：TIM3 PSC=0 时 <1098Hz 溢出 → 改 **PSC=71**。
7. **ST-Link error 138 / timeout**：`taskkill /F /IM stlinkserver.exe` 或命令行烧。
8. **PB15 按键没反应**：EXTI 配成上升沿了 → 应为**下降沿**。
